0 · 共同约束与方法

三个 workload 共用的写法

  • 执行模型：整片 wafer 是一个 unified GPU。host 端用 EnqueueLaunchKernel 一次 launch，driver 把 WG 分给 48 个 GPM。
  • pull 写法：每个 WG 自己读需要的数据，只写属于自己的输出行；没有任何跨 WG 的写冲突，所以不需要 atomic。
  • 索引在 host 端生成：KV 块表、MoE 的按 expert 排列、GNN 的采样子图，都在 Go 里生成后用 MemCopyH2D 拷到 GPU。拷贝开着 -magic-memory-copy，不计模拟时间。
  • LDS 只用简单读写：所有归约（max、sum、top-k）都用 LDS 树形归约加 barrier，不用 sub-group 函数。
  • 不用 private 数组：累加器写成一组标量（如 a00…a31、g0…g7），避免寄存器溢出到 scratch。

WG 和数据怎么落到 GPM（模拟器 driver 的规则，三个 workload 都一样）

WG 分配（mgpusim/driver/driver.go: distributeWGToGPUs）
  wgPerCU   = ceil(总 WG 数 / 1344)          1344 = 48 GPM × 28 CU
  GPM g 拿到  WG [g·28·wgPerCU, (g+1)·28·wgPerCU)   连续的一段，g 按 driver ID 1..48
  driver ID → tile：逐行排列、跳过中心 (3,3)；WG 少于 1344 时只用前 ceil(N/28) 个 GPM

页放置（mgpusim/driver/internal/memoryallocator.go）
  每个 buffer 单独按页（4 KB）切：每段 floor(页数/48) 页，第 i 段在第 i 个 GPM
  余数页全部给最后一个 GPM（tile 48）；不足 48 页的 buffer 整个放在第一个 GPM（tile 0）

所以一个 WG 读的数据是不是本地，取决于“它在 WG 序列里的位置”和“数据在 buffer 里的位置”是否落在同一个 1/48 段里。三个 workload 都靠间接下标（块表、排列、采样后的点 id）读数据，下标和 WG 的位置没有对应关系，所以大部分读是远程的。

编译、检查与正确性

  • 编译：build_hsaco.sh：OpenCL C 2.0，clang -target amdgcn-amd-amdhsa -mcpu=fiji -mcode-object-version=2，再用 ld.lld 链接成 kernels.hsaco，用 go:embed 打进二进制。
  • 检查：check_hsaco.sh 反汇编后逐条比对：出现 buffer/scratch、atomic、未实现的 flat/ds/SMEM 指令，或 private segment 不为 0，就拒绝安装。ALU 指令另用 opcheck 对照模拟器的实现表检查。
  • 正确性：每个 workload 都有 float64 的 host 参考实现（Reference）和单元测试。正式运行不跑 verify；开发时用极小输入在 emu 模式下跑一次，和参考实现逐元素比较（容差 1e-4 绝对 + 1e-3 相对）。
  • 读回：需要把 GPU 结果拷回 host 时（MoE 的 gate 输出、verify），打开 SetMagicCopyCoherent(true)：magic D2H 拷贝会先读 write-back L2 里的脏数据，否则只读 DRAM 会拿到旧值。这个拷贝同样不计时。
1 · PagedAttention（vLLM, SOSP'23）

一层 decode attention，KV cache 按块分页

只模拟一个 decode step 里一层的 attention（Q 已经算好，不含 QKV 投影和 FFN）。形状取 Llama-3-8B：32 个 query 头、8 个 KV 头（GQA，每个 KV 头被 4 个 query 头共享）、head dim 128。算法是 vLLM 的 PagedAttention 加 FlashDecoding 式的分段：长序列切成 64 token 一段，各段独立算，最后再合并。

93,600 token总上下文长度，平均约 1,418
16 token / 块vLLM 默认的 KV 块大小
794 MB实际访问到的 footprint（fp32）

输入与 KV 块分配（host.go）

  • 序列长度：从 Azure trace 的 19,366 个请求里均匀抽样。每条序列被看成“正在 decode 中途”：长度 = ContextTokens + g，g 在 1..GeneratedTokens 均匀取，再截到 [16, 8192]（Llama-3-8B 的上下文上限）。prompt 部分是 ContextTokens。
  • 块池：池的大小是这批序列所需块数的 2 倍（PoolFactor = 2）。BlockPool 模拟 vLLM v1 的 FreeKVCacheBlockQueue（不开 prefix caching）：分配从队头取，请求结束时按逆序把块放回队尾。
  • 先打乱池子（churn）：跑 8 轮“后台请求进出”。每轮不断接纳新请求，直到池子用到 90%；然后每个在跑的请求以 50% 概率结束。最后所有后台请求结束。这样空闲队列的顺序就和真实服务一样是乱的。
  • 再分配这批序列：66 条序列按随机顺序先一次性分到 prompt 的块（prefill），然后逐 token 地一起 decode，谁跨过块边界谁就再取一块。所以同一条序列的块在池里是分散的。
  • 工作列表：host 生成 (序列, 分段) 列表，按序列主序排列；Q 是 [-1, 1] 的随机数，K、V 按种子确定性生成（只拷贝用到的块）。

kernel 1：pa_partial（每个 WG 256 线程 = 4 个 wavefront）

一个 WG 负责一个 (序列, 64 token 的分段, KV 头)。WG 编号 = 工作项编号 × 8 + KV 头，所以同一分段的 8 个 KV 头是相邻的 8 个 WG。它同时算共享这个 KV 头的 4 个 query 头。

  1. QK 分数：线程 = (块内 token 0–15, 128 维中的一段 8 维)。逐块读块表 → 读 8 KB 的 K 块（每个字节只读一次）→ 每个线程对 4 个 query 头各算一个 8 维点积 → 写进 LDS pdot → 64 个线程把 16 段加起来，得到 4 个头 × 16 个 token 的分数，存在 LDS sc。分数直接乘 log2(e)/√D，后面用 v_exp_f32（2^x）算 softmax。
  2. 分段内 softmax：wave h 负责 query 头 h。在 LDS 里树形归约求 max，再求 Σ2^(s−max)，把分数换成未归一化的概率。
  3. P × V：wave w 取每个块里的第 w、w+4、w+8、w+12 个 token，每个 lane 负责 2 维；对 4 个头各累加一次。每个 V 字节也只读一次。4 个 wave 的部分和再经 LDS 合并。
  4. 写回：每个 query 头写 128 维的部分输出到 tmp_out，以及该分段的 max 和 exp-sum。

kernel 2：pa_reduce（每个 WG 64 线程）

一个 WG 负责一个 (序列, query 头)：先求所有分段 max 的最大值，再把每段按 2^(max_p − max) 重新缩放后加起来，除以总的 exp-sum。每个 lane 负责 2 维。这就是 FlashDecoding 的合并步骤，不需要 atomic。

  • GPM g 拿到连续的 252 个 WG，也就是约 31 个 (序列, 分段) × 8 个 KV 头。按序列主序，一个 GPM 大约负责 1–2 条序列的一部分分段，长序列会跨几个 GPM。
  • K、V 各是一个大 buffer，按页切成 48 段。一条序列的块散在整个池里，所以一个 WG 读的块约 47/48 在别的 GPM 上。实测 L1V 读远程比例 96.8%，远程平均延迟 2,871 ns（本地 73 ns）。

2 · MoE（DeepSeekMoE / DeepSeek-V3 风格）

一个 MoE 层：gate、按 expert 分组、expert FFN、合并

只模拟一个 MoE 层的 routed experts（不含 shared expert 和 attention）。结构同 DeepSeekMoE 16B：64 个 routed expert、每个 token 选 top-6、expert 是 SwiGLU FFN。为了把模拟时间控制在 3–5 小时，维度减半：hidden 1024（原 2048）、expert 中间维 704（原 1408）。batch 是 256 个 decode token。

路由与负载不均（host.go）

  • 输入：token 表示 x 和 gate 权重 Wg 是均匀随机数；expert 权重按 (seed, expert) 确定性生成，方差 1/fan_in。
  • 负载不均：随机权重的路由接近均匀，不真实。所以给每个 expert 加一个偏置 k·z_e（z_e ~ N(0,1)），只加在选 top-k 的分数上，不改合并权重（DeepSeek-V3 的 bias 做法）。k 在 host 上用二分法标定，使 max/mean 负载达到目标 1.75。
  • 按 expert 分组：gate kernel 跑完后，把 top-k 结果拷回 host（coherent magic copy，不计时），做一次按 expert 的计数排序（token 顺序稳定），得到：
    • perm_token[slot]：每个 slot 对应哪个 token；
    • inv_slot[t][k]：token t 的第 k 个选择落在哪个 slot；
    • tiles[n][3]：GEMM 的行 tile = (expert, 起始 slot, 行数 ≤ 32)，按 expert 顺序排列。
    真实系统里这一步是 GPU 上的一个小 kernel，这里放到 host 是因为它需要 atomic。

3 · R-GAT（MLPerf Inference v5.0 的 RGAT 任务）

异构图上两层采样的关系图注意力推理

MLPerf 的 RGAT 在 IGBH（5.47 亿点）上做 mini-batch 推理，模型是 4 头、512 维的 R-GAT。这里按比例缩小：数据集用 IGBH-tiny，320 个种子 paper，hidden 128，单头，不加 bias。图结构、关系类型和采样方式保持和 MLPerf 的 DGL 实现一致。

数据集与采样（graph.go、sample.go）

  • 读图：LoadIGBH 直接读 IGB 发布的 .npy 文件；特征按行按需读取。对每种关系建入边 CSR。
  • 采样：仿 DGL 的 MultiLayerNeighborSampler，从最后一层往输入层采：每个目标点对每种关系不放回地采最多 fanout 个入邻居。种子所在层 fanout 5，输入层 fanout 10。上一层的目标点 = 本层目标点 + 新采到的源点（按类型、排序）。
  • 采样结果：每层每种关系一个 block，内容是：目标点列表、去重排序后的源点列表、指向源点的 CSR（RowPtr/ColIdx），以及源点、目标点在本层输入表里的行号。同一目标类型的多个关系依次累加，最后一个关系做 ReLU（只在隐藏层）。
  • 模型参数：每个 (层, 关系) 一个 W（fan_in × 128）和两个 attention 向量 a_l、a_r。为了不对目标点做投影，host 预先算 v_r = W[:, head] · a_r[head]，于是目标点的分数 er = x_dst · v_r。

两个 kernel（每个 WG 256 线程）

  1. rgat_proj：一个 WG 负责 32 个采样源点 × 64 个输出列。按源点的行号从特征表 gather 32 行，和 W 做 tile GEMM（K 每次 32 放进 LDS），得到 h_r = x_src[src_ids] · W_r。第 1 层的输入是 1024 维原始特征，第 2 层是上一层的 128 维输出。
  2. rgat_agg：一个 WG 负责一个目标点 i。
    • 4 个 wave 轮流处理邻居 j，算 el_j = h_r[j] · a_l 的部分和；
    • 256 个线程一起算 er = x_dst[i] · v_r（第 1 层是 1024 维）；
    • e_ij = LeakyReLU(el_j + er, 0.2)，lane 0 串行做邻居间的 softmax（最多 32 个邻居）；
    • out[i] = prev[i] + Σ_j α_ij · h_r[j]。
    每个关系写自己的输出 buffer，prev 是上一个关系的 buffer。这样任何 buffer 都不会在被写之前被读，绕开了“kernel 之间不失效 L1”可能读到旧值的问题。

GPM 映射与访存

  • 每种点的特征表整张分配（例如 author 表 35.7 万 × 4 KB），按页切成 48 段；只把采样会碰到的行拷进去。采样到的点 id 是随机的，所以 gather 会分散到所有 GPM。实测 L1V 读远程 97.4%。
  • rgat_proj 的 WG 数 = ⌈源点数 / 32⌉ × 2，大多只有 26–340 个，又因为每个 WG 要读 32 × 1024 维特征而很长，只占 ≤ 13 个 GPM。这类 kernel 占了 85% 的运行时间；最大的聚合 kernel 有 1,344 个 WG，铺满 48 个 GPM。
  • 热点 owner 是分配器造成的：按 provider 统计远程读字节，最后一个 GPM（tile 48）占 16.7%，第一个 GPM（tile 0）占 7.1%。原因是 R-GAT 有大量中小 buffer（每个关系的行号、CSR、权重、attention 向量）：每个 buffer 的余数页都落在最后一个 GPM，不足 48 页的整个落在第一个 GPM。

// PagedAttention decode (vLLM, SOSP'23) with a FlashDecoding-style split
// over the sequence: one work-group per (sequence, KV head, partition) in
// pa_partial, then one work-group per (sequence, query head) in pa_reduce.
//
// Simulator rules (T17): no atomics, no private arrays (no scratch), only the
// DS opcodes ds_write_b32/write2_b32/read_b32/read2_b32/write2_b64/read_b64/
// read2_b64, fp32 only. build_hsaco.sh checks the generated code.
//
// Layouts (fp32):
//   q            [B][Hq][D]            Hq = Hkv * GQA
//   k_cache      [NB][Hkv][BS][D]      one physical KV block = BS tokens
//   v_cache      [NB][Hkv][BS][D]
//   block_tables [B][max_blocks]       physical block of logical block j
//   seq_lens     [B]
//   work         [n_work][2]           (sequence, partition), host-built
//   tmp_out      [B][Hq][max_parts][D] unnormalised partial outputs
//   max_logits   [B][Hq][max_parts]    log2-domain max of the partition
//   exp_sums     [B][Hq][max_parts]    sum of 2^(s - max) of the partition
//   out          [B][Hq][D]
//
// Scores are kept in the log2 domain (scale_log2 = log2(e) / sqrt(D)), so the
// softmax uses v_exp_f32 (2^x) directly; the result is the usual softmax.

#define D 128
#define GQA 4
#define BS 16
#define MAX_PART 512
#define NEG_INF (-3.0e38f)
// Index arithmetic is unsigned on purpose: signed (long)int*int compiles to
// v_mad_i64_i32 (VOP3a opcode 489), which the emulator does not implement;
// the unsigned form compiles to v_mad_u64_u32 / 32-bit multiplies.
#define UMUL(a, b) ((ulong)(uint)(a) * (ulong)(uint)(b))

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void pa_partial(__global const float *q,
                __global const float *k_cache,
                __global const float *v_cache,
                __global float *tmp_out,
                __global float *max_logits,
                __global float *exp_sums,
                // Unused: breaks the kernel arguments into runs shorter than
                // 64 bytes. The compiler loads all arguments at entry and
                // merges 16 contiguous dwords into s_load_dwordx16, which the
                // simulator does not implement (SMEM opcode 4).
                const int kernarg_gap,
                __global const int *block_tables,
                __global const int *seq_lens,
                __global const int *work,
                const float scale_log2,
                const int num_kv_heads,
                const int max_blocks,
                const int part_tokens,
                const int max_parts) {
  __local float sc[GQA * MAX_PART];  // [token][head] scores, then
                                     // probabilities, then
                                     // the cross-wave V partial sums
  __local float pdot[GQA * BS * 16]; // [token][slice][head] QK partials
  __local float red[GQA * 64];       // per-head reductions

  const int lid = get_local_id(0);
  const int wg = get_group_id(0);
  const int kvh = wg % num_kv_heads;
  const int item = wg / num_kv_heads;
  const int seq = work[2 * item];
  const int part = work[2 * item + 1];
  const int len = seq_lens[seq];
  const int tok0 = part * part_tokens;
  int ntok = len - tok0;
  if (ntok > part_tokens) {
    ntok = part_tokens;
  }
  const int blk0 = tok0 / BS;
  const int nblk = (ntok + BS - 1) / BS;
  const int nq = num_kv_heads * GQA;
  const int hq0 = kvh * GQA;
  const uint bt_base = (uint)seq * (uint)max_blocks + (uint)blk0;

  // ---- phase 1: scores. Thread = (token in block, 8-dim slice); the work-
  // group reads one 8 KB K block per step, each byte once.
  const int ktok = lid >> 4;
  const int kseg = lid & 15;
  const __global float *qp = q + ((uint)seq * nq + hq0) * D + kseg * 8;
  const float8 q0 = vload8(0, qp);
  const float8 q1 = vload8(0, qp + D);
  const float8 q2 = vload8(0, qp + 2 * D);
  const float8 q3 = vload8(0, qp + 3 * D);

  for (int b = 0; b < nblk; ++b) {
    const int phys = block_tables[bt_base + b];
    const int t = b * BS + ktok;
    float d0 = 0.0f, d1 = 0.0f, d2 = 0.0f, d3 = 0.0f;
    if (t < ntok) {
      const __global float *kp =
          k_cache + UMUL((uint)phys * num_kv_heads + kvh, BS * D) +
          ktok * D + kseg * 8;
      const float8 kv = vload8(0, kp);
      d0 = dot(q0.lo, kv.lo) + dot(q0.hi, kv.hi);
      d1 = dot(q1.lo, kv.lo) + dot(q1.hi, kv.hi);
      d2 = dot(q2.lo, kv.lo) + dot(q2.hi, kv.hi);
      d3 = dot(q3.lo, kv.lo) + dot(q3.hi, kv.hi);
    }
    pdot[(ktok * 16 + kseg) * GQA + 0] = d0;
    pdot[(ktok * 16 + kseg) * GQA + 1] = d1;
    pdot[(ktok * 16 + kseg) * GQA + 2] = d2;
    pdot[(ktok * 16 + kseg) * GQA + 3] = d3;
    barrier(CLK_LOCAL_MEM_FENCE);
    if (lid < GQA * BS) {
      const int h = lid >> 4;
      const int tk = lid & 15;
      float s = 0.0f;
      for (int i = 0; i < 16; ++i) {
        s += pdot[(tk * 16 + i) * GQA + h];
      }
      const int t2 = b * BS + tk;
      sc[t2 * GQA + h] = (t2 < ntok) ? s * scale_log2 : NEG_INF;
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }

  // ---- phase 2: softmax inside the partition. Wave h owns query head h.
  const int h = lid >> 6;
  const int lane = lid & 63;
  float m = NEG_INF;
  for (int t = lane; t < ntok; t += 64) {
    m = fmax(m, sc[t * GQA + h]);
  }
  red[h * 64 + lane] = m;
  barrier(CLK_LOCAL_MEM_FENCE);
  for (int s = 32; s > 0; s >>= 1) {
    if (lane < s) {
      red[h * 64 + lane] = fmax(red[h * 64 + lane], red[h * 64 + lane + s]);
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  m = red[h * 64];
  barrier(CLK_LOCAL_MEM_FENCE);

  float l = 0.0f;
  for (int t = lane; t < ntok; t += 64) {
    const float p = native_exp2(sc[t * GQA + h] - m);
    sc[t * GQA + h] = p;
    l += p;
  }
  red[h * 64 + lane] = l;
  barrier(CLK_LOCAL_MEM_FENCE);
  for (int s = 32; s > 0; s >>= 1) {
    if (lane < s) {
      red[h * 64 + lane] += red[h * 64 + lane + s];
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  l = red[h * 64];

  // ---- phase 3: P x V. Wave w takes tokens w, w+4, w+8, w+12 of every
  // block for all four heads; lane = 2 dims. Each V byte is read once.
  const int w = h;
  float a00 = 0.0f, a01 = 0.0f, a10 = 0.0f, a11 = 0.0f;
  float a20 = 0.0f, a21 = 0.0f, a30 = 0.0f, a31 = 0.0f;
  for (int b = 0; b < nblk; ++b) {
    const int phys = block_tables[bt_base + b];
    const __global float *vp =
        v_cache + UMUL((uint)phys * num_kv_heads + kvh, BS * D) + 2 * lane;
    for (int tk = w; tk < BS; tk += GQA) {
      const int t = b * BS + tk;
      if (t < ntok) {
        const float2 v = vload2(0, vp + tk * D);
        const float p0 = sc[t * GQA + 0];
        const float p1 = sc[t * GQA + 1];
        const float p2 = sc[t * GQA + 2];
        const float p3 = sc[t * GQA + 3];
        a00 += p0 * v.x;
        a01 += p0 * v.y;
        a10 += p1 * v.x;
        a11 += p1 * v.y;
        a20 += p2 * v.x;
        a21 += p2 * v.y;
        a30 += p3 * v.x;
        a31 += p3 * v.y;
      }
    }
  }
  barrier(CLK_LOCAL_MEM_FENCE); // all waves are done with the probabilities
  // sc reused as [dim][wave][head]: the 8 values of a thread sit within a
  // few dwords, so the compiler pairs them as ds_write2_b32 rather than the
  // unimplemented ds_write2st64_b32 (same for the reads below).
  const int d0i = (2 * lane) * GQA * GQA + w * GQA;
  const int d1i = (2 * lane + 1) * GQA * GQA + w * GQA;
  sc[d0i + 0] = a00;
  sc[d1i + 0] = a01;
  sc[d0i + 1] = a10;
  sc[d1i + 1] = a11;
  sc[d0i + 2] = a20;
  sc[d1i + 2] = a21;
  sc[d0i + 3] = a30;
  sc[d1i + 3] = a31;
  barrier(CLK_LOCAL_MEM_FENCE);

  float o0 = 0.0f, o1 = 0.0f;
  for (int ww = 0; ww < GQA; ++ww) {
    o0 += sc[(2 * lane) * GQA * GQA + ww * GQA + h];
    o1 += sc[(2 * lane + 1) * GQA * GQA + ww * GQA + h];
  }
  const uint o = ((uint)seq * nq + hq0 + h) * max_parts + part;
  vstore2((float2)(o0, o1), 0, tmp_out + UMUL(o, D) + 2 * lane);
  if (lane == 0) {
    max_logits[o] = m;
    exp_sums[o] = l;
  }
}

// One wavefront per (sequence, query head): merge the partitions.
__kernel __attribute__((reqd_work_group_size(64, 1, 1)))
void pa_reduce(__global const float *tmp_out,
               __global const float *max_logits,
               __global const float *exp_sums,
               __global const int *seq_lens,
               __global float *out,
               const int num_q_heads,
               const int part_tokens,
               const int max_parts) {
  const int lane = get_local_id(0);
  const int wg = get_group_id(0);
  const int seq = wg / num_q_heads;
  const int qh = wg % num_q_heads;
  const int len = seq_lens[seq];
  const int np = (len + part_tokens - 1) / part_tokens;
  const uint base = ((uint)seq * num_q_heads + qh) * max_parts;

  float gm = NEG_INF;
  for (int p = 0; p < np; ++p) {
    gm = fmax(gm, max_logits[base + p]);
  }
  float gl = 0.0f, a0 = 0.0f, a1 = 0.0f;
  for (int p = 0; p < np; ++p) {
    const float wgt = native_exp2(max_logits[base + p] - gm);
    gl += wgt * exp_sums[base + p];
    const float2 v = vload2(0, tmp_out + UMUL(base + p, D) + 2 * lane);
    a0 += wgt * v.x;
    a1 += wgt * v.y;
  }
  const float inv = native_recip(gl);
  vstore2((float2)(a0 * inv, a1 * inv), 0,
          out + UMUL((uint)seq * num_q_heads + qh, D) + 2 * lane);
}

// Model shape constants compiled into kernels.cl.
const (
	HeadDim   = 128 // D
	GQA       = 4   // query heads per KV head
	BlockSize = 16  // tokens per KV block (vLLM default)
	MaxPart   = 512 // largest partition the kernel's LDS holds
)

// LenDist is a log-normal context-length distribution clipped to
// [Min, Max]. Mean is the mean of the unclipped distribution and Sigma the
// standard deviation of ln(length); Mu = ln(Mean) - Sigma^2/2.
type LenDist struct {
	Mean  float64
	Sigma float64
	Min   int
	Max   int
}

// Mu returns the location parameter of the log-normal distribution.
func (d LenDist) Mu() float64 { return math.Log(d.Mean) - d.Sigma*d.Sigma/2 }

// SampleSeqLens draws n context lengths.
func SampleSeqLens(rng *rand.Rand, n int, d LenDist) []int {
	if d.Mean <= 0 || d.Sigma < 0 || d.Min < 1 || d.Max < d.Min {
		panic(fmt.Sprintf("pagedattn: invalid length distribution %+v", d))
	}
	mu := d.Mu()
	out := make([]int, n)
	for i := range out {
		l := int(math.Round(math.Exp(mu + d.Sigma*rng.NormFloat64())))
		if l < d.Min {
			l = d.Min
		}
		if l > d.Max {
			l = d.Max
		}
		out[i] = l
	}
	return out
}

// LenSource draws the context length of a sequence in the decode batch
// (total = prompt + tokens generated so far, prompt < total) and the final
// length of a background request (for the allocator history).
type LenSource interface {
	Sample(rng *rand.Rand) (total, prompt int)
	Request(rng *rand.Rand) int
	Describe() string
}

// Sample implements LenSource: a log-normal total, prompt = a U(0.2, 0.8)
// fraction of it.
func (d LenDist) Sample(rng *rand.Rand) (total, prompt int) {
	total = SampleSeqLens(rng, 1, d)[0]
	prompt = int(math.Round((0.2 + 0.6*rng.Float64()) * float64(total)))
	return total, clampPrompt(prompt, total)
}

// Request implements LenSource.
func (d LenDist) Request(rng *rand.Rand) int { return SampleSeqLens(rng, 1, d)[0] }

// Describe implements LenSource.
func (d LenDist) Describe() string {
	return fmt.Sprintf("lognormal(mean=%g,sigma=%g,min=%d,max=%d)", d.Mean, d.Sigma, d.Min, d.Max)
}

func clampPrompt(prompt, total int) int {
	if prompt >= total {
		prompt = total - 1
	}
	if prompt < 1 {
		prompt = 1
	}
	return prompt
}

// TraceRequest is one request of a serving trace.
type TraceRequest struct{ Context, Generated int }

// TraceDist samples requests uniformly from a trace (Azure LLM inference
// trace 2023, conversation service, by default). A request caught in the
// middle of its decode phase has context Context + g tokens, with g uniform
// in 1..Generated (1 if Generated is 0); the prompt is Context. Lengths are
// clipped to [Min, Max] (Max = the model context, 8192 for Llama-3-8B).
type TraceDist struct {
	Name     string
	Reqs     []TraceRequest
	Min, Max int
}

func (d TraceDist) clip(l int) int {
	if l < d.Min {
		l = d.Min
	}
	if l > d.Max {
		l = d.Max
	}
	return l
}

// Sample implements LenSource.
func (d TraceDist) Sample(rng *rand.Rand) (total, prompt int) {
	r := d.Reqs[rng.Intn(len(d.Reqs))]
	g := 1
	if r.Generated > 1 {
		g = 1 + rng.Intn(r.Generated)
	}
	total = d.clip(r.Context + g)
	return total, clampPrompt(r.Context, total)
}

// Request implements LenSource: the request's final length.
func (d TraceDist) Request(rng *rand.Rand) int {
	r := d.Reqs[rng.Intn(len(d.Reqs))]
	return d.clip(r.Context + r.Generated)
}

// Describe implements LenSource.
func (d TraceDist) Describe() string {
	return fmt.Sprintf("trace(%s,requests=%d,min=%d,max=%d)", d.Name, len(d.Reqs), d.Min, d.Max)
}

// BlockPool models vLLM's free KV-block queue (v1 FreeKVCacheBlockQueue
// without prefix caching): allocation pops from the head, a finished
// request's blocks are appended to the tail in reverse order.
type BlockPool struct {
	free []int // FIFO; free[head:] are free
	head int
	n    int
}

// NewBlockPool returns a pool whose free queue is 0..n-1.
func NewBlockPool(n int) *BlockPool {
	p := &BlockPool{free: make([]int, n), n: n}
	for i := range p.free {
		p.free[i] = i
	}
	return p
}

// NumBlocks returns the pool size.
func (p *BlockPool) NumBlocks() int { return p.n }

// NumFree returns the number of free blocks.
func (p *BlockPool) NumFree() int { return len(p.free) - p.head }

// Alloc pops the block at the head of the free queue.
func (p *BlockPool) Alloc() int {
	if p.NumFree() == 0 {
		panic("pagedattn: KV block pool exhausted")
	}
	b := p.free[p.head]
	p.head++
	if p.head > len(p.free)/2 && p.head > 1024 {
		p.free = append([]int(nil), p.free[p.head:]...)
		p.head = 0
	}
	return b
}

// Free returns a request's blocks to the tail, last block first.
func (p *BlockPool) Free(blocks []int) {
	for i := len(blocks) - 1; i >= 0; i-- {
		p.free = append(p.free, blocks[i])
	}
}

// ChurnConfig describes the serving history simulated before the measured
// batch is allocated.
type ChurnConfig struct {
	Rounds    int     // admit/finish rounds
	Occupancy float64 // admit background requests until this pool fraction is used
	FinishP   float64 // probability that a live background request finishes per round
}

func blocksFor(tokens int) int { return (tokens + BlockSize - 1) / BlockSize }

// BuildBlockTables simulates the allocator and returns, for every sequence
// of the batch, its physical blocks in logical order.
//
// History: Rounds rounds in which background requests (final lengths from src)
// are admitted until Occupancy of the pool is in use, then each live one
// finishes with probability FinishP; finally all background requests finish.
// This leaves the free queue in a serving-like scrambled order.
//
// Batch: every sequence first allocates its prompt blocks at once (prefill
// of prompts[i] tokens, sequences admitted in random order), then the
// decode tokens are generated one step
// at a time for all sequences, a sequence taking a new block whenever it
// crosses a block boundary (vLLM appends one block per BlockSize tokens).
func BuildBlockTables(
	rng *rand.Rand, pool *BlockPool, lens, prompts []int, src LenSource,
	churn ChurnConfig,
) [][]int {
	var live [][]int
	for r := 0; r < churn.Rounds; r++ {
		target := int(churn.Occupancy * float64(pool.NumBlocks()))
		for pool.NumBlocks()-pool.NumFree() < target {
			nb := blocksFor(src.Request(rng))
			if nb > pool.NumFree() {
				break
			}
			req := make([]int, nb)
			for i := range req {
				req[i] = pool.Alloc()
			}
			live = append(live, req)
		}
		kept := live[:0]
		for _, req := range live {
			if rng.Float64() < churn.FinishP {
				pool.Free(req)
			} else {
				kept = append(kept, req)
			}
		}
		live = kept
	}
	rng.Shuffle(len(live), func(i, j int) { live[i], live[j] = live[j], live[i] })
	for _, req := range live {
		pool.Free(req)
	}

	n := len(lens)
	tables := make([][]int, n)
	cur := make([]int, n)
	for _, i := range rng.Perm(n) {
		prompt := prompts[i]
		for j := 0; j < blocksFor(prompt); j++ {
			tables[i] = append(tables[i], pool.Alloc())
		}
		cur[i] = prompt
	}
	for {
		progressed := false
		for i := 0; i < n; i++ {
			if cur[i] >= lens[i] {
				continue
			}
			progressed = true
			cur[i]++
			if blocksFor(cur[i]) > len(tables[i]) {
				tables[i] = append(tables[i], pool.Alloc())
			}
		}
		if !progressed {
			break
		}
	}
	return tables
}

// WorkList returns the (sequence, partition) items of pa_partial in launch
// order (sequence-major) and the largest partition count.
func WorkList(lens []int, partTokens int) (work []int32, maxParts int) {
	for s, l := range lens {
		np := (l + partTokens - 1) / partTokens
		if np > maxParts {
			maxParts = np
		}
		for p := 0; p < np; p++ {
			work = append(work, int32(s), int32(p))
		}
	}
	return work, maxParts
}

// Problem is a fully generated PagedAttention decode input.
type Problem struct {
	Batch, KVHeads, PartTokens int
	NumBlocks, MaxBlocks       int
	MaxParts                   int
	Lens                       []int
	Prompts                    []int
	Tables                     [][]int
	Work                       []int32 // pairs
	BlockTable                 []int32 // [Batch][MaxBlocks], -1 = unused
	Q                          []float32
	K, V                       []float32 // [NumBlocks][KVHeads][BlockSize][HeadDim]
}

// QHeads returns the number of query heads.
func (p *Problem) QHeads() int { return p.KVHeads * GQA }

// BlockFloats returns the floats of one physical block (all KV heads).
func (p *Problem) BlockFloats() int { return p.KVHeads * BlockSize * HeadDim }

// NumWork returns the number of (sequence, partition) items.
func (p *Problem) NumWork() int { return len(p.Work) / 2 }

// Params collects every knob of the generator.
type Params struct {
	Batch      int
	KVHeads    int
	PartTokens int
	PoolFactor float64 // pool blocks = PoolFactor * blocks the batch needs
	Dist       LenDist // used when LenSource is "lognormal"
	// LenSource: "azure" (Azure LLM inference trace 2023, conversation) or
	// "lognormal" (Dist).
	LenSource string
	Churn     ChurnConfig
	Seed      int64
}

// Source returns the length source selected by LenSource.
func (pr Params) Source() LenSource {
	switch pr.LenSource {
	case "", "azure":
		return TraceDist{Name: "azure-conv-2023", Reqs: AzureConvTrace(), Min: pr.Dist.Min, Max: pr.Dist.Max}
	case "lognormal":
		return pr.Dist
	}
	panic(fmt.Sprintf("pagedattn: unknown length source %q (azure, lognormal)", pr.LenSource))
}

// Generate builds the lengths, block tables, work list and the Q values.
// K and V are only filled for the blocks the batch uses (and only if
// withKV is set; otherwise the caller fills them block by block).
func Generate(pr Params, withKV bool) *Problem {
	if pr.PartTokens <= 0 || pr.PartTokens%BlockSize != 0 || pr.PartTokens > MaxPart {
		panic(fmt.Sprintf("pagedattn: partition must be a multiple of %d and <= %d, got %d",
			BlockSize, MaxPart, pr.PartTokens))
	}
	rng := rand.New(rand.NewSource(pr.Seed))
	p := &Problem{Batch: pr.Batch, KVHeads: pr.KVHeads, PartTokens: pr.PartTokens}
	src := pr.Source()
	p.Lens = make([]int, pr.Batch)
	p.Prompts = make([]int, pr.Batch)
	for i := range p.Lens {
		p.Lens[i], p.Prompts[i] = src.Sample(rng)
	}
	need := 0
	for _, l := range p.Lens {
		need += blocksFor(l)
		if blocksFor(l) > p.MaxBlocks {
			p.MaxBlocks = blocksFor(l)
		}
	}
	p.NumBlocks = int(math.Ceil(pr.PoolFactor * float64(need)))
	if p.NumBlocks < need {
		p.NumBlocks = need
	}
	pool := NewBlockPool(p.NumBlocks)
	p.Tables = BuildBlockTables(rng, pool, p.Lens, p.Prompts, src, pr.Churn)
	p.BlockTable = make([]int32, pr.Batch*p.MaxBlocks)
	for i := range p.BlockTable {
		p.BlockTable[i] = -1
	}
	for s, t := range p.Tables {
		for j, b := range t {
			p.BlockTable[s*p.MaxBlocks+j] = int32(b)
		}
	}
	p.Work, p.MaxParts = WorkList(p.Lens, pr.PartTokens)

	p.Q = make([]float32, pr.Batch*p.QHeads()*HeadDim)
	for i := range p.Q {
		p.Q[i] = rng.Float32()*2 - 1
	}
	if withKV {
		bf := p.BlockFloats()
		p.K = make([]float32, p.NumBlocks*bf)
		p.V = make([]float32, p.NumBlocks*bf)
		for _, t := range p.Tables {
			for _, b := range t {
				FillBlock(pr.Seed, b, p.K[b*bf:(b+1)*bf], p.V[b*bf:(b+1)*bf])
			}
		}
	}
	return p
}

func FillBlock(seed int64, b int, k, v []float32) {
	rng := rand.New(rand.NewSource(seed*1000003 + int64(b)))
	for i := range k {
		k[i] = rng.Float32()*2 - 1
	}
	for i := range v {
		v[i] = rng.Float32()*2 - 1
	}
}

// CheckBounds verifies every index the kernels dereference: the work list,
// the block-table entries of every touched logical block, and the largest
// element offsets into each buffer.
func (p *Problem) CheckBounds() error {
	nq := p.QHeads()
	for i := 0; i < p.NumWork(); i++ {
		s, part := int(p.Work[2*i]), int(p.Work[2*i+1])
		if s < 0 || s >= p.Batch {
			return fmt.Errorf("work %d: sequence %d out of range", i, s)
		}
		if part < 0 || part >= p.MaxParts || part*p.PartTokens >= p.Lens[s] {
			return fmt.Errorf("work %d: partition %d out of range", i, part)
		}
		blk0 := part * p.PartTokens / BlockSize
		ntok := p.Lens[s] - part*p.PartTokens
		if ntok > p.PartTokens {
			ntok = p.PartTokens
		}
		for b := 0; b < blocksFor(ntok); b++ {
			idx := s*p.MaxBlocks + blk0 + b
			if blk0+b >= p.MaxBlocks {
				return fmt.Errorf("work %d: logical block %d >= max %d", i, blk0+b, p.MaxBlocks)
			}
			phys := int(p.BlockTable[idx])
			if phys < 0 || phys >= p.NumBlocks {
				return fmt.Errorf("work %d: physical block %d out of pool %d", i, phys, p.NumBlocks)
			}
			last := ((phys*p.KVHeads+p.KVHeads-1)*BlockSize+BlockSize-1)*HeadDim + HeadDim - 1
			if last >= p.NumBlocks*p.BlockFloats() {
				return fmt.Errorf("work %d: K/V offset %d out of buffer", i, last)
			}
		}
		o := ((s*nq+nq-1)*p.MaxParts + part)
		if o >= p.Batch*nq*p.MaxParts {
			return fmt.Errorf("work %d: partial-output index %d out of range", i, o)
		}
	}
	seen := make(map[int32]bool)
	for _, b := range p.BlockTable {
		if b < 0 {
			continue
		}
		if seen[b] {
			return fmt.Errorf("physical block %d used twice", b)
		}
		seen[b] = true
	}
	return nil
}

// byte counted once per buffer).
type Footprint struct {
	KV, Q, Index, Partial, Out uint64
}

// Total returns the total footprint.
func (f Footprint) Total() uint64 { return f.KV + f.Q + f.Index + f.Partial + f.Out }

// Footprint computes the touched bytes.
func (p *Problem) Footprint() Footprint {
	var f Footprint
	tokens := 0
	blocks := 0
	for _, l := range p.Lens {
		tokens += l
		blocks += blocksFor(l)
	}
	f.KV = uint64(tokens) * uint64(p.KVHeads*HeadDim*4*2)
	f.Q = uint64(len(p.Q) * 4)
	f.Index = uint64(blocks*4 + p.Batch*4 + len(p.Work)*4)
	nParts := p.NumWork()
	f.Partial = uint64(nParts*p.QHeads()) * uint64(HeadDim*4+8)
	f.Out = uint64(p.Batch * p.QHeads() * HeadDim * 4)
	return f
}

// Reference computes the decode attention output [Batch][Hq][D] in float64
// with the textbook softmax (no partitioning).
func (p *Problem) Reference() []float32 {
	nq := p.QHeads()
	out := make([]float32, p.Batch*nq*HeadDim)
	scale := 1 / math.Sqrt(HeadDim)
	bf := p.BlockFloats()
	for s := 0; s < p.Batch; s++ {
		l := p.Lens[s]
		for qh := 0; qh < nq; qh++ {
			kvh := qh / GQA
			q := p.Q[(s*nq+qh)*HeadDim : (s*nq+qh+1)*HeadDim]
			scores := make([]float64, l)
			m := math.Inf(-1)
			for t := 0; t < l; t++ {
				b := p.Tables[s][t/BlockSize]
				k := p.K[b*bf+(kvh*BlockSize+t%BlockSize)*HeadDim:]
				dot := 0.0
				for d := 0; d < HeadDim; d++ {
					dot += float64(q[d]) * float64(k[d])
				}
				scores[t] = dot * scale
				m = math.Max(m, scores[t])
			}
			sum := 0.0
			acc := make([]float64, HeadDim)
			for t := 0; t < l; t++ {
				w := math.Exp(scores[t] - m)
				sum += w
				b := p.Tables[s][t/BlockSize]
				v := p.V[b*bf+(kvh*BlockSize+t%BlockSize)*HeadDim:]
				for d := 0; d < HeadDim; d++ {
					acc[d] += w * float64(v[d])
				}
			}
			for d := 0; d < HeadDim; d++ {
				out[(s*nq+qh)*HeadDim+d] = float32(acc[d] / sum)
			}
		}
	}
	return out
}

// PagedAttention decode (vLLM, SOSP'23) with the Llama-3-8B attention shape
// (32 query heads, 8 KV heads, head dim 128, GQA 4:1) and a FlashDecoding-
// style split over the context:

// wgGPM mirrors driver.distributeWGToGPUs: contiguous ranges of
// CUsPerGPM*ceil(n/totalCUs) work-groups per GPM.
func wgGPM(wg, n, gpms, cus int) int {
	per := cus * ((n-1)/(gpms*cus) + 1)
	g := wg / per
	if g >= gpms {
		g = gpms - 1
	}
	return g
}

func activeGPMs(n, gpms, cus int) int {
	per := cus * ((n-1)/(gpms*cus) + 1)
	a := (n + per - 1) / per
	if a > gpms {
		a = gpms
	}
	return a
}

// pageGPM mirrors the default unified allocator: a buffer of numPages pages
// is split into gpms contiguous parts of numPages/gpms pages (the last part
// takes the remainder; buffers under gpms pages live on the first GPM).
func pageGPM(byteOff, bufBytes uint64, gpms int) int {
	const page = 4096
	numPages := (bufBytes + page - 1) / page
	per := numPages / uint64(gpms)
	if per == 0 {
		return 0
	}
	g := int(byteOff / page / per)
	if g >= gpms {
		g = gpms - 1
	}
	return g
}

// expectedKVRemote returns the fraction of K/V bytes whose page lives on a
// GPM other than the one running the reading pa_partial work-group.
func (b *Benchmark) expectedKVRemote() float64 {

	nWG := p.NumWork() * p.KVHeads
	bufBytes := uint64(p.NumBlocks) * uint64(p.BlockFloats()) * 4
	headBytes := uint64(BlockSize * HeadDim * 4)
	var remote, total float64
	for wg := 0; wg < nWG; wg++ {
		item, kvh := wg/p.KVHeads, wg%p.KVHeads
		s, part := int(p.Work[2*item]), int(p.Work[2*item+1])
		g := wgGPM(wg, nWG, b.NumGPMs, b.CUsPerGPM)
		ntok := p.Lens[s] - part*p.PartTokens
		if ntok > p.PartTokens {
			ntok = p.PartTokens
		}
		blk0 := part * p.PartTokens / BlockSize
		for j := 0; j < blocksFor(ntok); j++ {
			phys := uint64(p.Tables[s][blk0+j])
			off := (phys*uint64(p.KVHeads) + uint64(kvh)) * headBytes
			nt := ntok - j*BlockSize
			if nt > BlockSize {
				nt = BlockSize
			}
			bytes := float64(nt * HeadDim * 4 * 2)
			total += bytes
			if pageGPM(off, bufBytes, b.NumGPMs) != g {
				remote += bytes
			}
		}
	}
	if total == 0 {
		return 0
	}
	return remote / total
}

//
//   moe_gate     one WG per token: logits = x . Wg, softmax over experts,
//                top-k by (prob + bias) in LDS; writes expert ids and weights
//                (the softmax probabilities, not renormalised).
//   (host)       groups the (token, k) pairs by expert: perm/offsets/tiles.
//   moe_dispatch one WG per permuted slot: xs[slot] = x[perm_token[slot]].
//   moe_up       one WG per (expert m-tile, F tile): act = silu(xs W1) * (xs W3)
//   moe_down     one WG per (expert m-tile, H tile): ys = act W2
//   moe_combine  one WG per token: out[t] = sum_k w[t][k] * ys[inv[t][k]]
//
// Simulator rules (T17): no atomics, no private arrays, only the implemented
// DS opcodes, fp32. build_hsaco.sh checks the generated code.
//
// Layouts: x [T][H], wg [H][E] (x . wg), bias [E], w1/w3 [E][H][F],
// w2 [E][F][H], xs/ys [S][H], act [S][F] with S = T * TOPK slots.

// neither of which the emulator implements.
#define IDX(a, b) ((uint)(a) * (uint)(b))
// 32-bit local id: shifts of the 64-bit get_local_id(0) become
// v_alignbit_b32 (VOP3a opcode 462), which the emulator does not implement.
#define LOCAL_ID ((int)__builtin_amdgcn_workitem_id_x())
// Store 8 floats as four 8-byte stores. Two 16-byte stores make clang
// insert "s_nop 0" (fiji store-data hazard), which hangs the timing CU
// (check_hsaco.sh); the empty asm keeps the stores from being merged.
#define STORE8(o, a, b, c, d, e, f, g, h)            \
  do {                                               \
    vstore2((float2)(a, b), 0, (o));                 \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(c, d), 0, (o) + 2);             \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(e, f), 0, (o) + 4);             \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(g, h), 0, (o) + 6);             \
  } while (0)

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void moe_gate(__global const float *x,
              __global const float *wg,
              __global const float *bias,
              __global int *topk_idx,
              __global float *topk_w,
              const int hidden,
              const int topk) {
  // Sizes NE + 1: arrays 64 dwords apart make the compiler pair stores as
  // ds_write2st64_b32, which the simulator does not implement.
  __local float part[4 * NE];
  __local float prob[NE + 1];
  __local float sel[NE + 1];
  __local float rv[NE + 1];
  __local int ri[NE + 1];

  const int lid = LOCAL_ID;
  const int t = get_group_id(0);
  const int e = lid & (NE - 1);
  const int s = lid >> 6; // 4 slices of the hidden dimension
  const int chunk = hidden / 4;

  // logits: wave s sums its slice; lanes are experts (coalesced rows of wg)
  const __global float *xp = x + IDX(t, hidden) + s * chunk;
  const __global float *wp = wg + IDX(s * chunk, NE) + e;
  float acc = 0.0f;
  for (uint h = 0; h < (uint)chunk; ++h) {
    acc += xp[h] * wp[h * NE];
  }
  part[e * 4 + s] = acc;
  barrier(CLK_LOCAL_MEM_FENCE);

  // softmax over the experts (wave 0)
  if (lid < NE) {
    const float l = part[e * 4] + part[e * 4 + 1] + part[e * 4 + 2] + part[e * 4 + 3];
    prob[e] = l;
    rv[e] = l;
  }
  barrier(CLK_LOCAL_MEM_FENCE);
  for (int st = NE / 2; st > 0; st >>= 1) {
    if (lid < st) {
      rv[lid] = fmax(rv[lid], rv[lid + st]);
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  const float mx = rv[0];
  barrier(CLK_LOCAL_MEM_FENCE);
  if (lid < NE) {
    const float p = native_exp2((prob[e] - mx) * LOG2E);
    prob[e] = p;
    rv[e] = p;
  }
  barrier(CLK_LOCAL_MEM_FENCE);
  for (int st = NE / 2; st > 0; st >>= 1) {
    if (lid < st) {
      rv[lid] += rv[lid + st];
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  const float inv = native_recip(rv[0]);
  barrier(CLK_LOCAL_MEM_FENCE);
  if (lid < NE) {
    prob[e] *= inv;
    sel[e] = prob[e] + bias[e];
  }
  barrier(CLK_LOCAL_MEM_FENCE);

  // top-k by repeated arg-max in LDS (ties: lower expert id)
  for (int k = 0; k < topk; ++k) {
    if (lid < NE) {
      rv[e] = sel[e];
      ri[e] = e;
    }
    barrier(CLK_LOCAL_MEM_FENCE);
    for (int st = NE / 2; st > 0; st >>= 1) {
      if (lid < st) {
        const float a = rv[lid], b = rv[lid + st];
        if (b > a || (b == a && ri[lid + st] < ri[lid])) {
          rv[lid] = b;
          ri[lid] = ri[lid + st];
        }
      }
      barrier(CLK_LOCAL_MEM_FENCE);
    }
    if (lid == 0) {
      const int best = ri[0];
      topk_idx[t * topk + k] = best;
      topk_w[t * topk + k] = prob[best];
      sel[best] = NEG_INF;
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
}

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void moe_dispatch(__global const float *x,
                  __global const int *perm_token,
                  __global float *xs,
                  const int hidden) {
  const int slot = get_group_id(0);
  const int lid = LOCAL_ID;
  const uint src = IDX(perm_token[slot], hidden);
  const uint dst = IDX(slot, hidden);
  for (int h = lid * 4; h < hidden; h += 256 * 4) {
    vstore4(vload4(0, x + src + h), 0, xs + dst + h);
  }
}

// Shared tiled GEMM body: C[TM][TN] = A[rows][K] * B[K][N] restricted to
// rows of one expert. Thread = (row r = lid / 8, 8 columns c0 = (lid % 8) * 8).
// a_lds [TM][TK], b_lds [TK][TN].

inline void load_a_tile(__local float *a_lds, __global const float *a,
                        int slot0, int rows, int lda, int k0, int lid) {
  // TM * TK = 1024 floats, 4 per thread
  const int r = lid >> 3;
  const int kk = (lid & 7) * 4;
  float4 v = (float4)(0.0f);
  if (r < rows) {
    v = vload4(0, a + IDX(slot0 + r, lda) + k0 + kk);
  }
  a_lds[r * TK + kk] = v.x;
  a_lds[r * TK + kk + 1] = v.y;
  a_lds[r * TK + kk + 2] = v.z;
  a_lds[r * TK + kk + 3] = v.w;
}

inline void load_b_tile(__local float *b_lds, __global const float *b,
                        int ldb, int k0, int n0, int lid) {
  // TK * TN = 2048 floats, 8 contiguous per thread (8 threads per 256-B row);
  // contiguous LDS stores avoid the unimplemented ds_write2st64_b32.
  const int k = lid >> 3;           // 0..31
  const int c = (lid & 7) * 8;      // 0..56
  const __global float *src = b + IDX(k0 + k, ldb) + n0 + c;
  const float4 v0 = vload4(0, src);
  const float4 v1 = vload4(0, src + 4);
  __local float *dst = b_lds + k * TN + c;
  dst[0] = v0.x;
  dst[1] = v0.y;
  dst[2] = v0.z;
  dst[3] = v0.w;
  dst[4] = v1.x;
  dst[5] = v1.y;
  dst[6] = v1.z;
  dst[7] = v1.w;
}

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void moe_up(__global const float *xs,
            __global const float *w1,
            __global const float *w3,
            __global const int *tiles,
            __global float *act,
            const int hidden,
            const int ffn,
            const int n_tiles_n) {
  __local float a_lds[TM * TK];
  __local float b1_lds[TK * TN];
  __local float b3_lds[TK * TN];

  const int lid = LOCAL_ID;
  const int wgid = get_group_id(0);
  const int mt = wgid / n_tiles_n;
  const int n0 = (wgid % n_tiles_n) * TN;
  const int e = tiles[3 * mt];
  const int slot0 = tiles[3 * mt + 1];
  const int rows = tiles[3 * mt + 2];
  const __global float *b1 = w1 + IDX(e, hidden * ffn);
  const __global float *b3 = w3 + IDX(e, hidden * ffn);

  const int r = lid >> 3;
  const int c0 = (lid & 7) * 8;
  float g0 = 0.0f, g1 = 0.0f, g2 = 0.0f, g3 = 0.0f;
  float g4 = 0.0f, g5 = 0.0f, g6 = 0.0f, g7 = 0.0f;
  float u0 = 0.0f, u1 = 0.0f, u2 = 0.0f, u3 = 0.0f;
  float u4 = 0.0f, u5 = 0.0f, u6 = 0.0f, u7 = 0.0f;

  for (int k0 = 0; k0 < hidden; k0 += TK) {
    load_a_tile(a_lds, xs, slot0, rows, hidden, k0, lid);
    load_b_tile(b1_lds, b1, ffn, k0, n0, lid);
    load_b_tile(b3_lds, b3, ffn, k0, n0, lid);
    barrier(CLK_LOCAL_MEM_FENCE);
    // fully unrolled: the loop exit test would be s_cmpk_eq_i32 (SOPK 2),
    // which the emulator does not implement
#pragma unroll
    for (int k = 0; k < TK; ++k) {
      const float a = a_lds[r * TK + k];
      const __local float *p1 = b1_lds + k * TN + c0;
      const __local float *p3 = b3_lds + k * TN + c0;
      g0 += a * p1[0]; g1 += a * p1[1]; g2 += a * p1[2]; g3 += a * p1[3];
      g4 += a * p1[4]; g5 += a * p1[5]; g6 += a * p1[6]; g7 += a * p1[7];
      u0 += a * p3[0]; u1 += a * p3[1]; u2 += a * p3[2]; u3 += a * p3[3];
      u4 += a * p3[4]; u5 += a * p3[5]; u6 += a * p3[6]; u7 += a * p3[7];
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  if (r < rows) {
    __global float *o = act + IDX(slot0 + r, ffn) + n0 + c0;
#define SWIGLU(g, u) ((g) * native_recip(1.0f + native_exp2(-(g) * LOG2E)) * (u))
    vstore4((float4)(SWIGLU(g0, u0), SWIGLU(g1, u1), SWIGLU(g2, u2), SWIGLU(g3, u3)), 0, o);
    vstore4((float4)(SWIGLU(g4, u4), SWIGLU(g5, u5), SWIGLU(g6, u6), SWIGLU(g7, u7)), 0, o + 4);
#undef SWIGLU
  }
}

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void moe_down(__global const float *act,
              __global const float *w2,
              __global const int *tiles,
              __global float *ys,
              const int hidden,
              const int ffn,
              const int n_tiles_n) {
  __local float a_lds[TM * TK];
  __local float b_lds[TK * TN];

  const int lid = LOCAL_ID;
  const int wgid = get_group_id(0);
  const int mt = wgid / n_tiles_n;
  const int n0 = (wgid % n_tiles_n) * TN;
  const int e = tiles[3 * mt];
  const int slot0 = tiles[3 * mt + 1];
  const int rows = tiles[3 * mt + 2];
  const __global float *b = w2 + IDX(e, ffn * hidden);

  const int r = lid >> 3;
  const int c0 = (lid & 7) * 8;
  float y0 = 0.0f, y1 = 0.0f, y2 = 0.0f, y3 = 0.0f;
  float y4 = 0.0f, y5 = 0.0f, y6 = 0.0f, y7 = 0.0f;

  for (int k0 = 0; k0 < ffn; k0 += TK) {
    load_a_tile(a_lds, act, slot0, rows, ffn, k0, lid);
    load_b_tile(b_lds, b, hidden, k0, n0, lid);
    barrier(CLK_LOCAL_MEM_FENCE);
    // fully unrolled: the loop exit test would be s_cmpk_eq_i32 (SOPK 2),
    // which the emulator does not implement
#pragma unroll
    for (int k = 0; k < TK; ++k) {
      const float a = a_lds[r * TK + k];
      const __local float *p = b_lds + k * TN + c0;
      y0 += a * p[0]; y1 += a * p[1]; y2 += a * p[2]; y3 += a * p[3];
      y4 += a * p[4]; y5 += a * p[5]; y6 += a * p[6]; y7 += a * p[7];
    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  if (r < rows) {
    __global float *o = ys + IDX(slot0 + r, hidden) + n0 + c0;
    STORE8(o, y0, y1, y2, y3, y4, y5, y6, y7);
  }
}

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void moe_combine(__global const float *ys,
                 __global const int *inv_slot,
                 __global const float *topk_w,
                 __global float *out,
                 const int hidden,
                 const int topk) {
  const int t = get_group_id(0);
  const int lid = LOCAL_ID;
  for (int h = lid * 4; h < hidden; h += 256 * 4) {
    float4 acc = (float4)(0.0f);
    for (int k = 0; k < topk; ++k) {
      const float w = topk_w[t * topk + k];
      const int slot = inv_slot[t * topk + k];
      acc += w * vload4(0, ys + IDX(slot, hidden) + h);
    }
    vstore4(acc, 0, out + IDX(t, hidden) + h);
  }
}

package moe

import (
	"fmt"
	"math"
	"math/rand"
	"sort"
)

// Constants compiled into kernels.cl.
const (
	NumExperts = 64 // NE: routed experts (DeepSeekMoE 16B has 64)
	TileM      = 32 // TM: slots per GEMM tile
	TileN      = 64 // TN: output columns per GEMM tile
	TileK      = 32 // TK: reduction chunk
)

// Params collects every knob of the generator.
type Params struct {
	Tokens int // decode batch
	Hidden int // model dimension (multiple of 64)
	FFN    int // expert intermediate dimension (multiple of 64)
	TopK   int
	// Skew is the target max/mean expert load. A per-expert bias added to
	// the routing score (not to the combine weight) is scaled until the
	// host-side routing reaches it; 0 disables the bias ("uniform").
	Skew float64
	Seed int64
}

// Problem holds the generated inputs (expert weights are generated per
// expert on demand, see ExpertWeights).
type Problem struct {
	Params
	X     []float32 // [T][H]
	Wg    []float32 // [H][E]
	Bias  []float32 // [E]
	BiasZ []float64 // [E] unscaled bias direction
	BiasK float64   // chosen bias scale
}

// Validate checks the shape constraints of the kernels.
func (p Params) Validate() error {
	switch {
	case p.Tokens <= 0 || p.TopK <= 0 || p.TopK > NumExperts:
		return fmt.Errorf("moe: bad tokens %d / top-k %d", p.Tokens, p.TopK)
	case p.Hidden <= 0 || p.Hidden%TileN != 0 || p.Hidden%TileK != 0 || p.Hidden%4 != 0:
		return fmt.Errorf("moe: hidden %d must be a multiple of %d", p.Hidden, TileN)
	case p.FFN <= 0 || p.FFN%TileN != 0 || p.FFN%TileK != 0:
		return fmt.Errorf("moe: ffn %d must be a multiple of %d", p.FFN, TileN)
	case uint64(NumExperts)*uint64(p.Hidden)*uint64(p.FFN) >= 1<<32:
		return fmt.Errorf("moe: expert weights exceed 2^32 elements (32-bit kernel offsets)")
	case uint64(p.Tokens*p.TopK)*uint64(p.Hidden+p.FFN) >= 1<<32:
		return fmt.Errorf("moe: activations exceed 2^32 elements")
	}
	return nil
}

func uniform(rng *rand.Rand, out []float32, a float64) {
	for i := range out {
		out[i] = float32((rng.Float64()*2 - 1) * a)
	}
}

// ExpertWeights returns expert e's W1, W3 ([H][F]) and W2 ([F][H]),
// uniform with variance 1/fan_in, deterministic in (seed, e).
func ExpertWeights(seed int64, e, hidden, ffn int) (w1, w3, w2 []float32) {
	rng := rand.New(rand.NewSource(seed*7919 + int64(e) + 1))
	w1 = make([]float32, hidden*ffn)
	w3 = make([]float32, hidden*ffn)
	w2 = make([]float32, ffn*hidden)
	uniform(rng, w1, math.Sqrt(3/float64(hidden)))
	uniform(rng, w3, math.Sqrt(3/float64(hidden)))
	uniform(rng, w2, math.Sqrt(3/float64(ffn)))
	return
}

// Generate builds x, the gate weights and the calibrated bias.
func Generate(pr Params) *Problem {
	if err := pr.Validate(); err != nil {
		panic(err)
	}
	rng := rand.New(rand.NewSource(pr.Seed))
	p := &Problem{Params: pr}
	p.X = make([]float32, pr.Tokens*pr.Hidden)
	uniform(rng, p.X, 1)
	p.Wg = make([]float32, pr.Hidden*NumExperts)
	uniform(rng, p.Wg, math.Sqrt(3/float64(pr.Hidden)))
	p.BiasZ = make([]float64, NumExperts)
	for e := range p.BiasZ {
		p.BiasZ[e] = rng.NormFloat64()
	}
	probs := p.GateProbs()
	p.BiasK = CalibrateBias(probs, p.BiasZ, pr.TopK, pr.Skew)
	p.Bias = make([]float32, NumExperts)
	for e := range p.Bias {
		p.Bias[e] = float32(p.BiasK * p.BiasZ[e])
	}
	return p
}

// GateProbs returns the softmax gate probabilities [T][E] in float64.
func (p *Problem) GateProbs() [][]float64 {
	out := make([][]float64, p.Tokens)
	for t := range out {
		l := make([]float64, NumExperts)
		m := math.Inf(-1)
		for e := 0; e < NumExperts; e++ {
			s := 0.0
			for h := 0; h < p.Hidden; h++ {
				s += float64(p.X[t*p.Hidden+h]) * float64(p.Wg[h*NumExperts+e])
			}
			l[e] = s
			m = math.Max(m, s)
		}
		sum := 0.0
		for e := range l {
			l[e] = math.Exp(l[e] - m)
			sum += l[e]
		}
		for e := range l {
			l[e] /= sum
		}
		out[t] = l
	}
	return out
}

// TopK returns the k experts with the largest prob+bias (ties: lower id).
func TopK(prob []float64, bias []float64, k int) []int {
	idx := make([]int, len(prob))
	for i := range idx {
		idx[i] = i
	}
	sort.SliceStable(idx, func(a, b int) bool {
		return prob[idx[a]]+bias[idx[a]] > prob[idx[b]]+bias[idx[b]]
	})
	return idx[:k]
}

// Loads returns the number of (token, k) pairs routed to each expert.
func Loads(topk [][]int) []int {
	l := make([]int, NumExperts)
	for _, r := range topk {
		for _, e := range r {
			l[e]++
		}
	}
	return l
}

// MaxOverMean returns max/mean of the expert loads.
func MaxOverMean(loads []int) float64 {
	sum, mx := 0, 0
	for _, l := range loads {
		sum += l
		if l > mx {
			mx = l
		}
	}
	return float64(mx) / (float64(sum) / float64(len(loads)))
}

func route(probs [][]float64, z []float64, k int, scale float64) [][]int {
	bias := make([]float64, len(z))
	for i := range z {
		bias[i] = scale * z[i]
	}
	out := make([][]int, len(probs))
	for t, pr := range probs {
		out[t] = TopK(pr, bias, k)
	}
	return out
}

// CalibrateBias returns the bias scale whose routing gets closest to the
// target max/mean load (bisection over [0, 1]; the probabilities are about
// 1/E, so a scale of 1 dominates them). target <= the unbiased ratio gives 0.
func CalibrateBias(probs [][]float64, z []float64, k int, target float64) float64 {
	if target <= 0 {
		return 0
	}
	ratio := func(s float64) float64 { return MaxOverMean(Loads(route(probs, z, k, s))) }
	if ratio(0) >= target {
		return 0
	}
	lo, hi := 0.0, 1.0
	if ratio(hi) < target {
		return hi
	}
	for i := 0; i < 40; i++ {
		mid := (lo + hi) / 2
		if ratio(mid) < target {
			lo = mid
		} else {
			hi = mid
		}
	}
	return hi
}

// Routing is the host-built permutation (grouped by expert).
type Routing struct {
	Loads     []int
	Offsets   []int   // [E+1] first slot of each expert
	PermToken []int32 // [S] token of each slot
	InvSlot   []int32 // [T*K] slot of (token, k)
	Tiles     []int32 // [n][3] (expert, first slot, rows <= TileM)
}

// NumTiles returns the number of GEMM row tiles.
func (r *Routing) NumTiles() int { return len(r.Tiles) / 3 }

// MaxTiles bounds the tile count for any routing of s slots.
func MaxTiles(s int) int { return s/TileM + NumExperts }

// BuildRouting groups the (token, k) pairs by expert (stable in token
// order), the counting sort a real MoE runtime does on the GPU.
func BuildRouting(topkIdx []int32, tokens, k int) (*Routing, error) {
	r := &Routing{Loads: make([]int, NumExperts), Offsets: make([]int, NumExperts+1)}
	if len(topkIdx) != tokens*k {
		return nil, fmt.Errorf("moe: %d top-k entries for %d x %d", len(topkIdx), tokens, k)
	}
	for i, e := range topkIdx {
		if e < 0 || int(e) >= NumExperts {
			return nil, fmt.Errorf("moe: top-k entry %d = expert %d out of range", i, e)
		}
		r.Loads[e]++
	}
	for e := 0; e < NumExperts; e++ {
		r.Offsets[e+1] = r.Offsets[e] + r.Loads[e]
	}
	next := append([]int(nil), r.Offsets[:NumExperts]...)
	r.PermToken = make([]int32, tokens*k)
	r.InvSlot = make([]int32, tokens*k)
	for t := 0; t < tokens; t++ {
		seen := map[int32]bool{}
		for j := 0; j < k; j++ {
			e := topkIdx[t*k+j]
			if seen[e] {
				return nil, fmt.Errorf("moe: token %d routed twice to expert %d", t, e)
			}
			seen[e] = true
			s := next[e]
			next[e]++
			r.PermToken[s] = int32(t)
			r.InvSlot[t*k+j] = int32(s)
		}
	}
	for e := 0; e < NumExperts; e++ {
		for s := r.Offsets[e]; s < r.Offsets[e+1]; s += TileM {
			rows := r.Offsets[e+1] - s
			if rows > TileM {
				rows = TileM
			}
			r.Tiles = append(r.Tiles, int32(e), int32(s), int32(rows))
		}
	}
	return r, nil
}

// Check verifies every index the kernels dereference.
func (r *Routing) Check(tokens, k int) error {
	s := tokens * k
	for i, t := range r.PermToken {
		if t < 0 || int(t) >= tokens {
			return fmt.Errorf("perm[%d] = token %d out of range", i, t)
		}
	}
	for i, v := range r.InvSlot {
		if v < 0 || int(v) >= s || int(r.PermToken[v]) != i/k {
			return fmt.Errorf("inv[%d] = slot %d inconsistent", i, v)
		}
	}
	covered := 0
	for i := 0; i < r.NumTiles(); i++ {
		e, s0, rows := r.Tiles[3*i], int(r.Tiles[3*i+1]), int(r.Tiles[3*i+2])
		if e < 0 || int(e) >= NumExperts || rows <= 0 || rows > TileM ||
			s0 < r.Offsets[e] || s0+rows > r.Offsets[e+1] {
			return fmt.Errorf("tile %d (%d, %d, %d) out of range", i, e, s0, rows)
		}
		covered += rows
	}
	if covered != s {
		return fmt.Errorf("tiles cover %d of %d slots", covered, s)
	}
	if r.NumTiles() > MaxTiles(s) {
		return fmt.Errorf("%d tiles > bound %d", r.NumTiles(), MaxTiles(s))
	}
	return nil
}

func silu(x float64) float64 { return x / (1 + math.Exp(-x)) }

// Reference computes out [T][H] in float64 for the given routing decision
// (topkIdx/topkW as produced by the gate kernel).
func (p *Problem) Reference(topkIdx []int32, topkW []float32) []float32 {
	out := make([]float64, p.Tokens*p.Hidden)
	H, F := p.Hidden, p.FFN
	byExpert := map[int][]int{} // expert -> list of t*K+j
	for i, e := range topkIdx {
		byExpert[int(e)] = append(byExpert[int(e)], i)
	}
	act := make([]float64, F)
	for e, list := range byExpert {
		w1, w3, w2 := ExpertWeights(p.Seed, e, H, F)
		for _, i := range list {
			t := i / p.TopK
			x := p.X[t*H : (t+1)*H]
			for f := 0; f < F; f++ {
				g, u := 0.0, 0.0
				for h := 0; h < H; h++ {
					g += float64(x[h]) * float64(w1[h*F+f])
					u += float64(x[h]) * float64(w3[h*F+f])
				}
				act[f] = silu(g) * u
			}
			w := float64(topkW[i])
			for h := 0; h < H; h++ {
				y := 0.0
				for f := 0; f < F; f++ {
					y += act[f] * float64(w2[f*H+h])
				}
				out[t*H+h] += w * y
			}
		}
	}
	res := make([]float32, len(out))
	for i, v := range out {
		res[i] = float32(v)
	}
	return res
}

// HostTopK returns the [T*K] expert ids the gate kernel selects (float64
// host gate: softmax probabilities + bias, ties to the lower id).
func (p *Problem) HostTopK() []int32 {
	probs := p.GateProbs()
	bias := make([]float64, NumExperts)
	for e := range bias {
		bias[e] = float64(p.Bias[e])
	}
	out := make([]int32, 0, p.Tokens*p.TopK)
	for t := range probs {
		for _, e := range TopK(probs[t], bias, p.TopK) {
			out = append(out, int32(e))
		}
	}
	return out
}

	probs := p.GateProbs()

		wErr = math.Max(wErr, math.Abs(float64(b.gpuTopW[i])-probs[i/K][b.gpuTopK[i]]))
	}
	got := make([]float32, p.Tokens*p.Hidden)
	b.driver.MemCopyD2H(b.context, got, b.dOut)
	ref := p.Reference(b.gpuTopK, b.gpuTopW)
	maxErr, bad := 0.0, 0
	for i := range ref {
		e := math.Abs(float64(got[i]) - float64(ref[i]))
		maxErr = math.Max(maxErr, e)
		if !(e <= 1e-4+1e-3*math.Abs(float64(ref[i]))) {
			if bad < 5 {
				log.Printf("moe: mismatch at %d: got %g want %g", i, got[i], ref[i])
			}
			bad++
		}
	}

		"elements=%d,max_abs_err=%.3g,mismatches=%d\n",
		selDiff, wErr, len(ref), maxErr, bad)

	H, F := p.Hidden, p.FFN
	rows, ld := H, F
	if down {
		rows, ld = F, H
	}
	bufBytes := uint64(NumExperts) * uint64(H*F) * 4
	ntn := ncols / TileN
	per := b.CUsPerGPM * ((nWG-1)/(b.NumGPMs*b.CUsPerGPM) + 1)
	pagesPerGPM := (bufBytes + 4095) / 4096 / uint64(b.NumGPMs)

		g := wg / per
		if g >= b.NumGPMs {
			g = b.NumGPMs - 1
		}
		e := uint64(r.Tiles[3*(wg/ntn)])
		n0 := uint64((wg % ntn) * TileN)
		for k := 0; k < rows; k++ {
			off := (e*uint64(H*F) + uint64(k)*uint64(ld) + n0) * 4

				owner = int(off / 4096 / pagesPerGPM)
				if owner >= b.NumGPMs {
					owner = b.NumGPMs - 1
				}
			}
			total += TileN * 4
			if owner != g {
				remote += TileN * 4
			}
		}
	}

// R-GAT style sampled aggregation (MLPerf Inference RGAT on IGBH), T17 W-C.
// One layer = for every relation r (src type -> dst type) of the sampled
// block, two kernels (no atomics, pull only):
//
//   rgat_proj  WG per (32 sampled source rows, 64 output columns):
//              h_r[k] = x_src[src_ids[k]] . W_r     (gather + projection)
//   rgat_agg   WG per destination node i of the block, for every head
//              hd (columns C_hd = [hd*d, (hd+1)*d), d = f_h / heads):
//              er    = x_dst[dst_ids[i]] . v_r[hd]  (v_r[hd] = W_r[:,C_hd]
//                                                    a_r[C_hd], host)
//              el_j  = h_r[j][C_hd] . a_l[C_hd]     for sampled neighbours j
//              e_ij  = LeakyReLU(el_j + er, 0.2), softmax over j
//              out[i][C_hd] = (acc ? prev[i][C_hd] : 0)
//                             + sum_j alpha_ij h_r[j][C_hd]
//              (ReLU on the last relation of a hidden layer; the heads are
//              concatenated, GATConv concat=True)
//
// The relations into one destination type run one after another; each
// writes its own output buffer, prev = the previous relation's (each row is
// read and written by its own WG). No buffer is read before it is written:
// with magic copies the timing model never invalidates the L1 caches
// between kernels, so a read-modify-write of one buffer across kernels
// could hit a stale L1V line.
//
// Simulator rules (T17): no atomics, no private arrays, only implemented DS
// opcodes, fp32. 32-bit element offsets (every buffer < 2^32 elements; the
// host checks it).

#define MAXDEG 32
#define TM 32
#define TN 64
#define TK 32
#define NEG_INF (-3.0e38f)
#define LOG2E 1.4426950408889634f
#define IDX(a, b) ((uint)(a) * (uint)(b))
#define LOCAL_ID ((int)__builtin_amdgcn_workitem_id_x())
// Store 8 floats as four 8-byte stores. Two 16-byte stores make clang
// insert "s_nop 0" (fiji store-data hazard), which hangs the timing CU
// (check_hsaco.sh); the empty asm keeps the stores from being merged.
#define STORE8(o, a, b, c, d, e, f, g, h)            \
  do {                                               \
    vstore2((float2)(a, b), 0, (o));                 \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(c, d), 0, (o) + 2);             \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(e, f), 0, (o) + 4);             \
    __asm__ volatile("" ::: "memory");               \
    vstore2((float2)(g, h), 0, (o) + 6);             \
  } while (0)

void rgat_proj(__global const float *x,
               __global const int *src_ids,
               __global const float *w,
               __global float *h,
               const int n_rows,
               const int f_in,
               const int f_out,
               const int n_tiles_n) {
  __local float a_lds[TM * TK];
  __local float b_lds[TK * TN];

  const int lid = LOCAL_ID;
  const int wg = get_group_id(0);
  const int row0 = (wg / n_tiles_n) * TM;
  const int n0 = (wg % n_tiles_n) * TN;
  const int r = lid >> 3;
  const int c0 = (lid & 7) * 8;

  // the gathered feature row this thread loads into a_lds (row r, 4 floats)
  const int ar = lid >> 3;
  const int ak = (lid & 7) * 4;
  const bool a_valid = row0 + ar < n_rows;
  const uint a_base = a_valid ? IDX(src_ids[row0 + ar], f_in) : 0;
  // b tile: row bk, 8 contiguous columns
  const int bk = lid >> 3;
  const int bc = (lid & 7) * 8;

  float y0 = 0.0f, y1 = 0.0f, y2 = 0.0f, y3 = 0.0f;
  float y4 = 0.0f, y5 = 0.0f, y6 = 0.0f, y7 = 0.0f;
  for (int k0 = 0; k0 < f_in; k0 += TK) {
    float4 v = (float4)(0.0f);
    if (a_valid) {
      v = vload4(0, x + a_base + k0 + ak);
    }
    a_lds[ar * TK + ak] = v.x;
    a_lds[ar * TK + ak + 1] = v.y;
    a_lds[ar * TK + ak + 2] = v.z;
    a_lds[ar * TK + ak + 3] = v.w;
    const __global float *src = w + IDX(k0 + bk, f_out) + n0 + bc;
    const float4 b0 = vload4(0, src);
    const float4 b1 = vload4(0, src + 4);
    __local float *dst = b_lds + bk * TN + bc;
    dst[0] = b0.x;
    dst[1] = b0.y;
    dst[2] = b0.z;
    dst[3] = b0.w;
    dst[4] = b1.x;
    dst[5] = b1.y;
    dst[6] = b1.z;

    }
    barrier(CLK_LOCAL_MEM_FENCE);
  }
  if (row0 + r < n_rows) {
    __global float *o = h + IDX(row0 + r, f_out) + n0 + c0;
    STORE8(o, y0, y1, y2, y3, y4, y5, y6, y7);
  }
}

__kernel __attribute__((reqd_work_group_size(256, 1, 1)))
void rgat_agg(__global const float *h_src,
              __global const float *x_dst,
              __global const int *dst_ids,
              __global const int *row_ptr,
              __global const int *col_idx,
              __global const float *attn_l,
              __global const float *v_r,
              __global const float *prev,
              __global float *out,
              const int f_in,
              const int f_h,
              const int use_acc,
              const int act,
              const int heads) {
  // one LDS array, score at offset 0 (see build_hsaco.sh)
  __local float lds[MAXDEG + 320 + 64 * MAXDEG];
  __local float *score = lds;               // [MAXDEG]
  __local float *rpart = lds + MAXDEG;      // [64][5]
  __local float *part = lds + MAXDEG + 320; // [lane][neighbour]

  const int i = get_group_id(0);
  const int lid = LOCAL_ID;
  const int wave = lid >> 6;
  const int lane = lid & 63;
  const int beg = row_ptr[(uint)i];
  int deg = row_ptr[(uint)i + 1u] - beg;
  if (deg > MAXDEG) {
    deg = MAXDEG;
  }

  // heads one after another; the barriers inside keep the LDS reuse safe
  // (score/part/rpart of head hd+1 are written only after every thread has
  // passed a barrier that follows its use of head hd)
  const int dh = f_h / heads;
  for (int hd = 0; hd < heads; ++hd) {
    const int c0 = hd * dh;
    const __global float *vh = v_r + IDX(hd, f_in);
    // el_j partial sums: wave w takes neighbours w, w+4, ...
    for (int j = wave; j < deg; j += 4) {
      const __global float *hj = h_src + IDX(col_idx[beg + j], f_h);
      float s = 0.0f;
      for (int c = c0 + lane; c < c0 + dh; c += 64) {
        s += hj[c] * attn_l[c];
      }
      part[lane * MAXDEG + j] = s;
    }
    // er_i = x_dst . v_r over f_in, all 256 threads; partials stored with a
    // stride of 5 so no two operands are a multiple of 64 dwords apart
    // (ds_read2st64_b32 is not implemented)
    {
      const __global float *xi = x_dst + IDX(dst_ids[i], f_in);
      float s = 0.0f;
      for (int c = lid; c < f_in; c += 256) {
        s += xi[c] * vh[c];
      }
      rpart[lane * 5 + wave] = s;
    }
    barrier(CLK_LOCAL_MEM_FENCE);
    if (lid < 64) {
      rpart[lid * 5 + 4] = rpart[lid * 5] + rpart[lid * 5 + 1] +
                           rpart[lid * 5 + 2] + rpart[lid * 5 + 3];
    }
    barrier(CLK_LOCAL_MEM_FENCE);
    for (int st = 32; st > 0; st >>= 1) {
      if (lid < st) {
        rpart[lid * 5 + 4] += rpart[(lid + st) * 5 + 4];
      }
      barrier(CLK_LOCAL_MEM_FENCE);
    }
    if (lid < deg) {
      float s = 0.0f;
  #pragma unroll
      for (int c = 0; c < 64; ++c) {
        s += part[c * MAXDEG + lid];
      }
      score[lid] = s;
    }
    barrier(CLK_LOCAL_MEM_FENCE);

    if (lid == 0) {
      const float er = rpart[4];
      float m = NEG_INF;
      for (int j = 0; j < deg; ++j) {
        float e = score[j] + er;
        e = e > 0.0f ? e : 0.2f * e;
        score[j] = e;
        m = fmax(m, e);
      }
      float sum = 0.0f;
      for (int j = 0; j < deg; ++j) {
        const float p = native_exp2((score[j] - m) * LOG2E);
        score[j] = p;
        sum += p;
      }
      const float inv = deg > 0 ? native_recip(sum) : 0.0f;
      for (int j = 0; j < deg; ++j) {
        score[j] *= inv;
      }
    }
    barrier(CLK_LOCAL_MEM_FENCE);

    for (int c = c0 + lid; c < c0 + dh; c += 256) {
      const uint o = IDX(i, f_h) + c;
      float acc = use_acc ? prev[o] : 0.0f;
      for (int j = 0; j < deg; ++j) {
        acc += score[j] * h_src[IDX(col_idx[beg + j], f_h) + c];
      }
      if (act) {
        acc = fmax(acc, 0.0f);
      }
      out[o] = acc;
    }
  }
}

		ptr := make([]int32, nd+1)
		for k := range r.DstIDs {
			s, d := r.SrcIDs[k], r.DstIDs[k]

				return fmt.Errorf("%s: edge %d (%d -> %d) out of range", r.Name, k, s, d)
			}
			ptr[d+1]++
		}
		for i := 1; i <= nd; i++ {
			ptr[i] += ptr[i-1]
		}
		next := append([]int32(nil), ptr[:nd]...)
		src := make([]int32, len(r.SrcIDs))
		for k := range r.DstIDs {
			d := r.DstIDs[k]
			src[next[d]] = r.SrcIDs[k]
			next[d]++
		}
		g.in[ri] = csr{ptr, src}
	}
	return nil
}

var npyShape = regexp.MustCompile(`'shape':\s*\(([0-9,\s]*)\)`)
var npyDescr = regexp.MustCompile(`'descr':\s*'([^']*)'`)

type npyMatrix struct {
	path       string
	f          *os.File
	off        int64
	rows, cols int
}

func npyHeader(f *os.File) (descr string, shape []int, off int64, err error) {
	head := make([]byte, 10)
	if _, err = f.ReadAt(head, 0); err != nil {
		return
	}
	if string(head[1:6]) != "NUMPY" {
		return "", nil, 0, fmt.Errorf("%s: not an npy file", f.Name())
	}
	var hlen int64
	switch head[6] {
	case 1:
		hlen, off = int64(binary.LittleEndian.Uint16(head[8:10])), 10
	default:
		b := make([]byte, 4)
		if _, err = f.ReadAt(b, 8); err != nil {
			return
		}
		hlen, off = int64(binary.LittleEndian.Uint32(b)), 12
	}
	h := make([]byte, hlen)
	if _, err = f.ReadAt(h, off); err != nil {
		return
	}
	off += hlen
	hs := string(h)
	if strings.Contains(hs, "'fortran_order': True") {
		return "", nil, 0, fmt.Errorf("%s: fortran order not supported", f.Name())
	}
	m := npyDescr.FindStringSubmatch(hs)
	s := npyShape.FindStringSubmatch(hs)
	if m == nil || s == nil {
		return "", nil, 0, fmt.Errorf("%s: bad npy header %q", f.Name(), hs)
	}
	descr = m[1]
	for _, p := range strings.Split(s[1], ",") {
		if p = strings.TrimSpace(p); p != "" {
			v, e := strconv.Atoi(p)
			if e != nil {
				return "", nil, 0, e
			}
			shape = append(shape, v)
		}
	}
	return descr, shape, off, nil
}

func openNpyMatrix(path, wantDescr string) (*npyMatrix, error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	descr, shape, off, err := npyHeader(f)
	if err != nil {
		return nil, err
	}
	if descr != wantDescr || len(shape) != 2 {
		return nil, fmt.Errorf("%s: dtype %s shape %v, want %s 2-D", path, descr, shape, wantDescr)
	}
	return &npyMatrix{path, f, off, shape[0], shape[1]}, nil
}

// Row reads one float32 row.
func (m *npyMatrix) Row(id int, out []float32) {
	buf := make([]byte, 4*m.cols)
	if _, err := m.f.ReadAt(buf, m.off+int64(id)*int64(len(buf))); err != nil {
		panic(fmt.Sprintf("%s row %d: %v", m.path, id, err))
	}
	for i := range out[:m.cols] {
		out[i] = math.Float32frombits(binary.LittleEndian.Uint32(buf[4*i:]))
	}
}

func readEdgeIndex(path string) (src, dst []int32, err error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, nil, err
	}
	defer f.Close()
	descr, shape, off, err := npyHeader(f)
	if err != nil {
		return nil, nil, err
	}
	if descr != "<i8" || len(shape) != 2 || shape[1] != 2 {
		return nil, nil, fmt.Errorf("%s: dtype %s shape %v, want <i8 (E, 2)", path, descr, shape)
	}
	buf := make([]byte, 16*shape[0])
	if _, err = f.ReadAt(buf, off); err != nil {
		return nil, nil, err
	}
	src = make([]int32, shape[0])
	dst = make([]int32, shape[0])
	for k := range src {
		s := int64(binary.LittleEndian.Uint64(buf[16*k:]))
		d := int64(binary.LittleEndian.Uint64(buf[16*k+8:]))
		if s > math.MaxInt32 || d > math.MaxInt32 {
			return nil, nil, fmt.Errorf("%s: id beyond int32", path)
		}
		src[k], dst[k] = int32(s), int32(d)
	}
	return src, dst, nil
}

// Block is the sampled bipartite graph of one relation in one layer.
type Block struct {
	Layer            int
	Rel              int
	RelName          string
	SrcType, DstType string
	// DstNodes are the layer's destination nodes of DstType (global ids);
	// the block's destination i is DstNodes[i].
	DstNodes []int32
	// SrcNodes are the unique sampled sources (global ids, sorted).
	SrcNodes []int32
	// RowPtr/ColIdx: sampled neighbours of destination i, as indices into
	// SrcNodes.
	RowPtr []int32
	ColIdx []int32
	// Row indices into the layer's input tables (raw features by global id
	// for layer 0, the previous layer's output rows otherwise).
	SrcRows []int32
	DstRows []int32
	// Accumulate into the output rows (not the first relation of DstType),
	// and apply ReLU (last relation of DstType in a hidden layer).
	UseAcc, Act bool
}

// Sample is a sampled mini-batch: Dst[l][t] lists the destination nodes of
// type t of layer l (layer 0 reads the raw features, the last layer
// produces the seeds' outputs), Blocks[l] the blocks of layer l.
type Sample struct {
	Seeds   []int32
	Fanouts []int // per layer, input layer first (DGL order)
	Dst     []map[string][]int32
	Blocks  [][]Block
}

// SampleBlocks samples like DGL's MultiLayerNeighborSampler on a
// heterograph: from the last layer to the first, every destination node
// samples up to fanout in-neighbours per relation, without replacement; the
// destination nodes of layer l-1 are those of layer l followed by the newly
// sampled sources (sorted), per type.
func SampleBlocks(g *Graph, seedType string, seeds []int32, fanouts []int, rng *rand.Rand) *Sample {
	L := len(fanouts)
	s := &Sample{Seeds: seeds, Fanouts: fanouts, Dst: make([]map[string][]int32, L),
		Blocks: make([][]Block, L)}
	s.Dst[L-1] = map[string][]int32{seedType: append([]int32(nil), seeds...)}
	for l := L - 1; l >= 0; l-- {
		newSrc := map[string]map[int32]bool{}
		for ri, r := range g.Rels {
			dsts := s.Dst[l][r.Dst]
			if len(dsts) == 0 {
				continue
			}
			adj := g.in[ri]
			b := Block{Layer: l, Rel: ri, RelName: r.Name, SrcType: r.Src, DstType: r.Dst,
				DstNodes: dsts, RowPtr: make([]int32, len(dsts)+1)}
			var nbrs [][]int32
			uniq := map[int32]bool{}
			for _, d := range dsts {
				cand := adj.src[adj.ptr[d]:adj.ptr[d+1]]
				pick := cand
				if len(cand) > fanouts[l] {
					idx := rng.Perm(len(cand))[:fanouts[l]]
					sort.Ints(idx)
					pick = make([]int32, fanouts[l])
					for k, i := range idx {
						pick[k] = cand[i]
					}
				}
				nbrs = append(nbrs, pick)
				for _, v := range pick {
					uniq[v] = true
				}
			}
			if len(uniq) == 0 {
				continue
			}
			for v := range uniq {
				b.SrcNodes = append(b.SrcNodes, v)
			}
			sort.Slice(b.SrcNodes, func(i, j int) bool { return b.SrcNodes[i] < b.SrcNodes[j] })
			pos := make(map[int32]int32, len(b.SrcNodes))
			for i, v := range b.SrcNodes {
				pos[v] = int32(i)
			}
			for i, p := range nbrs {
				for _, v := range p {
					b.ColIdx = append(b.ColIdx, pos[v])
				}
				b.RowPtr[i+1] = int32(len(b.ColIdx))
			}
			if newSrc[r.Src] == nil {
				newSrc[r.Src] = map[int32]bool{}
			}
			for _, v := range b.SrcNodes {
				newSrc[r.Src][v] = true
			}
			s.Blocks[l] = append(s.Blocks[l], b)
		}
		if l > 0 {
			prev := map[string][]int32{}
			for t, dsts := range s.Dst[l] {
				prev[t] = append([]int32(nil), dsts...)
			}
			for t, set := range newSrc {
				in := map[int32]bool{}
				for _, v := range prev[t] {
					in[v] = true
				}
				var add []int32
				for v := range set {
					if !in[v] {
						add = append(add, v)
					}
				}
				sort.Slice(add, func(i, j int) bool { return add[i] < add[j] })
				prev[t] = append(prev[t], add...)
			}
			s.Dst[l-1] = prev
		}
	}
	// input rows, accumulation and activation flags
	for l := 0; l < L; l++ {
		pos := map[string]map[int32]int32{}
		if l > 0 {
			for t, nodes := range s.Dst[l-1] {
				pos[t] = map[int32]int32{}
				for i, v := range nodes {
					pos[t][v] = int32(i)
				}
			}
		}
		row := func(t string, v int32) int32 {
			if l == 0 {
				return v
			}
			p, ok := pos[t][v]
			if !ok {
				panic(fmt.Sprintf("rgat: node %s/%d missing from layer %d", t, v, l-1))
			}
			return p
		}
		seen := map[string]int{}
		last := map[string]int{}
		for i, b := range s.Blocks[l] {
			last[b.DstType] = i
		}
		for i := range s.Blocks[l] {
			b := &s.Blocks[l][i]
			b.UseAcc = seen[b.DstType] > 0
			seen[b.DstType]++
			b.Act = l < L-1 && last[b.DstType] == i
			b.SrcRows = make([]int32, len(b.SrcNodes))
			for k, v := range b.SrcNodes {
				b.SrcRows[k] = row(b.SrcType, v)
			}
			b.DstRows = make([]int32, len(b.DstNodes))
			for k, v := range b.DstNodes {
				b.DstRows[k] = row(b.DstType, v)
			}
		}
	}

// width with the heads concatenated (GATConv concat=True): head hd owns the
// columns [hd*d, (hd+1)*d), d = Hidden/Heads, and its attention vectors are

	Hidden int
	Heads  int

	W      map[[2]int][]float32 // (layer, relation) -> [FIn][Hidden]
	AL, AR map[[2]int][]float32 // attention vectors [Hidden]
	V      map[[2]int][]float32 // per head W[:,head] . AR[head], [Heads][FIn]
}

// NewModel draws uniform weights with variance 1/fan_in for every block.
func NewModel(s *Sample, featDim, hidden, heads int, seed int64) *Model {
	m := &Model{Hidden: hidden, Heads: heads, W: map[[2]int][]float32{}, AL: map[[2]int][]float32{},
		AR: map[[2]int][]float32{}, V: map[[2]int][]float32{}}
	for l := range s.Blocks {
		fin := featDim
		if l > 0 {
			fin = hidden
		}
		m.FIn = append(m.FIn, fin)
		for _, b := range s.Blocks[l] {
			k := [2]int{l, b.Rel}
			rng := rand.New(rand.NewSource(seed*104729 + int64(l)*131 + int64(b.Rel)))
			w := make([]float32, fin*hidden)
			a := math.Sqrt(3 / float64(fin))
			for i := range w {
				w[i] = float32((rng.Float64()*2 - 1) * a)
			}
			al := make([]float32, hidden)
			ar := make([]float32, hidden)
			aa := math.Sqrt(3 / float64(hidden))
			for i := range al {
				al[i] = float32((rng.Float64()*2 - 1) * aa)
				ar[i] = float32((rng.Float64()*2 - 1) * aa)
			}
			d := hidden / heads
			v := make([]float32, heads*fin)
			for hd := 0; hd < heads; hd++ {
				for i := 0; i < fin; i++ {
					s := 0.0
					for c := hd * d; c < (hd+1)*d; c++ {
						s += float64(w[i*hidden+c]) * float64(ar[c])
					}
					v[hd*fin+i] = float32(s)
				}
			}
			m.W[k], m.AL[k], m.AR[k], m.V[k] = w, al, ar, v
		}
	}
	return m
}

// Reference computes every layer's outputs in float64: out[l][t] is
// [len(Dst[l][t])][Hidden]. feat(t, id) returns a raw feature row.
func Reference(s *Sample, m *Model, feat func(t string, id int32) []float32) []map[string][]float64 {
	L := len(s.Blocks)
	H := m.Hidden
	outs := make([]map[string][]float64, L)
	for l := 0; l < L; l++ {
		fin := m.FIn[l]
		input := func(t string, rowIdx int32, id int32) []float64 {
			x := make([]float64, fin)
			if l == 0 {
				for i, v := range feat(t, id) {
					x[i] = float64(v)
				}
				return x
			}
			copy(x, outs[l-1][t][int(rowIdx)*H:(int(rowIdx)+1)*H])
			return x
		}
		outs[l] = map[string][]float64{}
		for t, nodes := range s.Dst[l] {
			outs[l][t] = make([]float64, len(nodes)*H)
		}
		for _, b := range s.Blocks[l] {
			k := [2]int{l, b.Rel}
			w, al, ar := m.W[k], m.AL[k], m.AR[k]
			h := make([][]float64, len(b.SrcNodes))
			for j := range b.SrcNodes {
				x := input(b.SrcType, b.SrcRows[j], b.SrcNodes[j])
				h[j] = make([]float64, H)
				for c := 0; c < H; c++ {
					s := 0.0
					for i := 0; i < fin; i++ {
						s += x[i] * float64(w[i*H+c])
					}
					h[j][c] = s
				}
			}
			out := outs[l][b.DstType]
			d := H / m.Heads
			for i := range b.DstNodes {
				xd := input(b.DstType, b.DstRows[i], b.DstNodes[i])
				beg, end := b.RowPtr[i], b.RowPtr[i+1]
				row := out[i*H : (i+1)*H]
				if !b.UseAcc {
					for c := range row {
						row[c] = 0
					}
				}
				for hd := 0; hd < m.Heads; hd++ {
					c0, c1 := hd*d, (hd+1)*d
					er := 0.0
					for c := c0; c < c1; c++ {
						p := 0.0
						for q := 0; q < fin; q++ {
							p += xd[q] * float64(w[q*H+c])
						}
						er += p * float64(ar[c])
					}
					sc := make([]float64, end-beg)
					mx := math.Inf(-1)
					for e := beg; e < end; e++ {
						el := 0.0
						for c := c0; c < c1; c++ {
							el += h[b.ColIdx[e]][c] * float64(al[c])
						}
						v := el + er
						if v < 0 {
							v *= 0.2
						}
						sc[e-beg] = v
						mx = math.Max(mx, v)
					}
					sum := 0.0
					for q := range sc {
						sc[q] = math.Exp(sc[q] - mx)
						sum += sc[q]
					}
					for e := beg; e < end; e++ {
						for c := c0; c < c1; c++ {
							row[c] += sc[e-beg] / sum * h[b.ColIdx[e]][c]
						}
					}
				}
				if b.Act {
					for c := range row {
						row[c] = math.Max(row[c], 0)
					}
				}
			}
		}
	}
	return outs
}

// Prepare loads the graph, samples and builds the model (host only).
func Prepare(pr Params) (*Graph, *Sample, *Model, error) {
	for _, f := range pr.Fanouts {
		if f < 1 || f > MaxDeg {
			return nil, nil, nil, fmt.Errorf("rgat: fanout %d outside 1..%d", f, MaxDeg)
		}
	}
	if pr.Hidden <= 0 || pr.Hidden%TileN != 0 {
		return nil, nil, nil, fmt.Errorf("rgat: hidden %d must be a multiple of %d", pr.Hidden, TileN)
	}
	if pr.Heads < 1 || pr.Hidden%pr.Heads != 0 {
		return nil, nil, nil, fmt.Errorf("rgat: heads %d must divide hidden %d", pr.Heads, pr.Hidden)
	}
	var g *Graph
	var err error
	if pr.DataDir != "" {
		g, err = LoadIGBH(pr.DataDir)
		if err != nil {
			return nil, nil, nil, err
		}
	} else {
		g = SyntheticIGBH(pr.SynthPapers, pr.SynthDim, pr.Seed)
	}
	if g.FeatDim%TileK != 0 {
		return nil, nil, nil, fmt.Errorf("rgat: feature dim %d not a multiple of %d", g.FeatDim, TileK)
	}
	for _, t := range g.Types {
		if uint64(g.NumNodes[t])*uint64(g.FeatDim) >= 1<<32 {
			return nil, nil, nil, fmt.Errorf("rgat: %s table exceeds 2^32 elements", t)
		}
	}
	rng := rand.New(rand.NewSource(pr.Seed))
	if pr.Seeds > g.NumNodes["paper"] {
		return nil, nil, nil, fmt.Errorf("rgat: %d seeds > %d papers", pr.Seeds, g.NumNodes["paper"])
	}
	seeds := make([]int32, pr.Seeds)
	for i, v := range rng.Perm(g.NumNodes["paper"])[:pr.Seeds] {
		seeds[i] = int32(v)
	}
	s := SampleBlocks(g, "paper", seeds, pr.Fanouts, rng)
	m := NewModel(s, g.FeatDim, pr.Hidden, pr.Heads, pr.Seed)
	if err := s.Check(g, m); err != nil {
		return nil, nil, nil, err
	}
	return g, s, m, nil
}

// Check verifies every index the kernels dereference.
func (s *Sample) Check(g *Graph, m *Model) error {
	for l, blocks := range s.Blocks {
		for _, b := range blocks {
			rows := func(t string) int {
				if l == 0 {
					return g.NumNodes[t]
				}
				return len(s.Dst[l-1][t])
			}
			for _, r := range b.SrcRows {
				if r < 0 || int(r) >= rows(b.SrcType) {
					return fmt.Errorf("layer %d %s: src row %d out of range", l, b.RelName, r)
				}
			}
			for _, r := range b.DstRows {
				if r < 0 || int(r) >= rows(b.DstType) {
					return fmt.Errorf("layer %d %s: dst row %d out of range", l, b.RelName, r)
				}
			}
			if len(b.RowPtr) != len(b.DstNodes)+1 || int(b.RowPtr[len(b.DstNodes)]) != len(b.ColIdx) {
				return fmt.Errorf("layer %d %s: bad row pointer", l, b.RelName)
			}
			for i := range b.DstNodes {
				if d := b.RowPtr[i+1] - b.RowPtr[i]; d < 0 || int(d) > MaxDeg || int(d) > s.Fanouts[l] {
					return fmt.Errorf("layer %d %s: degree %d", l, b.RelName, d)
				}
			}
			for _, c := range b.ColIdx {
				if c < 0 || int(c) >= len(b.SrcNodes) {
					return fmt.Errorf("layer %d %s: neighbour %d out of range", l, b.RelName, c)
				}
			}
		}
	}
	return nil
}

// Run samples on the host, uploads and launches every kernel.
func (b *Benchmark) Run() {
	b.driver.SelectGPU(b.context, b.gpus[0])
	// Verify copies results back through the write-back L2 (no time).
	b.driver.SetMagicCopyCoherent(true)
	g, s, m, err := Prepare(b.Params)
	if err != nil {
		log.Panic(err)
	}
	b.graph, b.sample, b.model = g, s, m
	H := m.Hidden
	q := b.driver.CreateCommandQueue(b.context)

	// raw feature tables: allocate whole, copy the touched rows
	tables := map[string]driver.Ptr{}
	touched := b.touchedRows()
	for _, t := range g.Types {
		tables[t] = b.alloc(4*g.NumNodes[t]*g.FeatDim, "rgat_feat_"+t)
		row := make([]float32, g.FeatDim)
		for _, id := range touched[t] {
			g.Feats[t].Row(int(id), row)
			b.driver.MemCopyH2D(b.context,
				tables[t]+driver.Ptr(uint64(id)*uint64(g.FeatDim)*4), row)
		}
	}
	b.outs = make([]map[string]driver.Ptr, len(s.Blocks))
	for l := range s.Blocks {
		// Every relation writes its own output buffer: out_r = out_{r-1} +
		// its contribution (the previous relation's buffer is passed as
		// prev). No buffer is read before a kernel writes it, so no L1V
		// can hold a stale line of it: with magic copies the timing model
		// never invalidates the L1 caches between kernels.
		b.outs[l] = map[string]driver.Ptr{}
		input := func(t string) driver.Ptr {
			if l == 0 {
				return tables[t]
			}
			return b.outs[l-1][t]
		}
		fin := m.FIn[l]
		for _, blk := range s.Blocks[l] {
			k := [2]int{l, blk.Rel}
			nm := fmt.Sprintf("rgat_l%d_%s", l, blk.RelName)
			dSrc := b.upload(nm+"_src_rows", blk.SrcRows, len(blk.SrcRows))
			dDst := b.upload(nm+"_dst_rows", blk.DstRows, len(blk.DstRows))
			dPtr := b.upload(nm+"_row_ptr", blk.RowPtr, len(blk.RowPtr))
			dCol := b.upload(nm+"_col_idx", blk.ColIdx, len(blk.ColIdx))
			dW := b.upload(nm+"_w", m.W[k], len(m.W[k]))
			dAL := b.upload(nm+"_attn_l", m.AL[k], len(m.AL[k]))
			dV := b.upload(nm+"_v", m.V[k], len(m.V[k]))
			dH := b.alloc(4*len(blk.SrcNodes)*H, nm+"_h")
			prev := driver.Ptr(0)
			if blk.UseAcc {
				prev = b.outs[l][blk.DstType]
			}
			dOut := b.alloc(4*len(s.Dst[l][blk.DstType])*H, nm+"_out")
			b.outs[l][blk.DstType] = dOut

			ntn := H / TileN
			nProj := (len(blk.SrcNodes) + TileM - 1) / TileM * ntn
			pa := ProjArgs{X: input(blk.SrcType), SrcIDs: dSrc, W: dW, H: dH,
				NRows: int32(len(blk.SrcNodes)), FIn: int32(fin), FOut: int32(H), NTilesN: int32(ntn)}
			b.driver.EnqueueLaunchKernel(q, b.proj, [3]uint32{uint32(nProj * wgSize), 1, 1},
				[3]uint16{wgSize, 1, 1}, &pa)
			aa := AggArgs{HSrc: dH, XDst: input(blk.DstType), DstIDs: dDst, RowPtr: dPtr,
				ColIdx: dCol, AttnL: dAL, VR: dV, Prev: prev, Out: dOut,
				FIn: int32(fin), FH: int32(H), UseAcc: b2i(blk.UseAcc), Act: b2i(blk.Act),
				Heads: int32(m.Heads)}
			b.driver.EnqueueLaunchKernel(q, b.agg, [3]uint32{uint32(len(blk.DstNodes) * wgSize), 1, 1},
				[3]uint16{wgSize, 1, 1}, &aa)
			b.launch = append(b.launch, launchInfo{"proj_" + nm[5:], nProj},
				launchInfo{"agg_" + nm[5:], len(blk.DstNodes)})
		}
	}
	b.report(touched)
	b.driver.DrainCommandQueue(q)
}

# unimplemented flat/ds opcodes). Needs clang with the amdgcn target, ld.lld,
# llvm-objdump, llvm-readelf and the ROCm device libs (yss2, not macOS).
#
# Usage: build_hsaco.sh [dir ...]      (default: every subdirectory with a
#                                       kernels.cl)
#
# check_hsaco.sh covers memory, LDS, SMEM and scratch. ALU opcodes the
# emulator lacks are found by opcheck (needs Go; run it where the simulator
# sources are):
#   llvm-objdump -d --mcpu=fiji <dir>/kernels.hsaco > k.dis
#   go run ./benchmarks/t17/opcheck -emu emu k.dis      (from mgpusim/)
#
# Patterns that clang 14 turns into instructions the simulator lacks, and
# the source-level way around them used in these kernels:
#   LDS arrays/strides of 64 dwords     -> ds_*2st64_b32: interleave/pad
#   4 contiguous aligned LDS loads      -> ds_read_b128: strided layout
# Implemented since commit "simulator: implement v_mad_i64_i32, ..." (the
# kernels written before still avoid them): s_load_dwordx16 (>= 64
# contiguous kernarg bytes), v_mad_i64_i32 (signed long index math),
# v_alignbit_b32 (64-bit id shifts), s_ashr_i64, s_addk_i32, s_cmpk_eq_i32.
# Fixed since commits "timing/cu: advance PC for scheduler-internal SOPP
# instructions" and "insts, emu: decode v_mad_u64_u32 (VOP3 488) as VOP3b"
# (the kernels written before still avoid them): s_nop in a kernel body
# (clang's fiji store-data hazard padding; used to hang the timing CU) and
# v_mad_u64_u32 (unsigned 64-bit int*int + 64; used to be decoded with a
# 32-bit dst).
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
CLANG="${CLANG:-clang}"
LD_LLD="${LD_LLD:-ld.lld}"
GPU="${GPU:-fiji}"
ROCM_DEVICE_LIB_PATH="${ROCM_DEVICE_LIB_PATH:-/usr/lib/x86_64-linux-gnu/amdgcn/bitcode}"

dirs=("$@")
if ((${#dirs[@]} == 0)); then
  for d in "$SCRIPT_DIR"/*/; do
    [[ -f "$d/kernels.cl" ]] && dirs+=("$(basename "$d")")
  done
fi

OBJ_DIR="$(mktemp -d "${TMPDIR:-/tmp}/t17-hsaco.XXXXXX")"
trap 'rm -rf "$OBJ_DIR"' EXIT

for d in "${dirs[@]}"; do
  [[ "$d" = /* ]] || d="$SCRIPT_DIR/$d"
  name="$(basename "$d")"
  out="$OBJ_DIR/$name.hsaco"
  "$CLANG" -x cl -target amdgcn-amd-amdhsa -mcpu="$GPU" -mcode-object-version=2 \
    -cl-std=CL2.0 --rocm-device-lib-path="$ROCM_DEVICE_LIB_PATH" \
    -c "$d/kernels.cl" -o "$OBJ_DIR/$name.o"
  "$LD_LLD" -shared "$OBJ_DIR/$name.o" -o "$out"
  # Only install the code object if it passes the check.
  GPU="$GPU" "$SCRIPT_DIR/check_hsaco.sh" "$out"
  cp "$out" "$d/kernels.hsaco"
  echo "built $d/kernels.hsaco"
done

#!/usr/bin/env bash
# Check that a code object only uses memory instructions the simulator
# implements (T17 step 0). Fails (exit 1) on:
#   - MUBUF/MTBUF/scratch instructions (buffer_*, tbuffer_*, scratch_*);
#     the simulator has no MUBUF/scratch support (emu/alu.go Run panics on the
#     format, timing/cu/scratchpadpreparer.go too);
#   - any atomic (flat_atomic_*, global_atomic_*, ds_*atomic-like ops);
#   - flat_* opcodes the emulator does not implement (emu/alu_flat.go
#     implements load ubyte/ushort/dword/x2/x4 and store dword/x2/x3/x4);
#   - ds_* outside the 7 implemented opcodes (emu/aluds.go);
#   - s_load/s_store/s_buffer_* other than s_load_dword/x2/x4/x8/x16
#     (emu/alu.go runSMEM and timing/cu/scalarunit.go implement SMEM 0-4);
#   - a kernel whose private segment (scratch) size is not 0;
#   - a scheduler-internal SOPP op other than s_nop, s_endpgm, s_barrier,
#     s_waitcnt inside a kernel body: emu/alu.go runSOPP has no case for
#     them (emulation panics) and the timing CU treats them as no-ops
#     (s_sethalt/s_setkill/s_trap/s_set_gpr_idx_* are not modeled). s_nop is
#     accepted: the timing scheduler used to complete it without advancing
#     the PC (hang), fixed in "timing/cu: advance PC for scheduler-internal
#     SOPP instructions". Padding after s_endpgm is never executed and is
#     ignored.
# Needs llvm-objdump and llvm-readelf (yss2). Usage: check_hsaco.sh a.hsaco...
set -euo pipefail

OBJDUMP="${LLVM_OBJDUMP:-llvm-objdump}"
READELF="${LLVM_READELF:-llvm-readelf}"
MCPU="${GPU:-fiji}"

ALLOWED_DS='^(ds_write_b32|ds_write2_b32|ds_read_b32|ds_read2_b32|ds_write2_b64|ds_read_b64|ds_read2_b64)$'
ALLOWED_SMEM='^(s_load_dword|s_load_dwordx2|s_load_dwordx4|s_load_dwordx8|s_load_dwordx16)$'
ALLOWED_FLAT='^(flat_load_ubyte|flat_load_ushort|flat_load_dword|flat_load_dwordx2|flat_load_dwordx4|flat_store_dword|flat_store_dwordx2|flat_store_dwordx3|flat_store_dwordx4)$'

status=0
for f in "$@"; do
  mnems="$("$OBJDUMP" -d --mcpu="$MCPU" "$f" |
    grep -oE '^[[:space:]]+[a-z][a-z0-9_]*' | sed -E 's/^[[:space:]]+//' | sort | uniq -c)"
  bad=""
  while read -r count m; do
    [[ -z "$m" ]] && continue
    case "$m" in
      buffer_* | tbuffer_* | scratch_* | global_* | *atomic*)
        bad+="  $m ($count)"$'\n' ;;
      flat_*)
        [[ "$m" =~ $ALLOWED_FLAT ]] || bad+="  $m ($count)"$'\n' ;;
      ds_*)
        [[ "$m" =~ $ALLOWED_DS ]] || bad+="  $m ($count)"$'\n' ;;
      s_load_* | s_store_* | s_buffer_* | s_dcache_* | s_memtime | s_memrealtime)
        [[ "$m" =~ $ALLOWED_SMEM ]] || bad+="  $m ($count)"$'\n' ;;
    esac
  done <<<"$mnems"

  # scheduler-internal ops in a kernel body (labels start a kernel,
  # s_endpgm ends its body; the padding after it is never executed)
  internal="$("$OBJDUMP" -d --mcpu="$MCPU" "$f" | awk '
    /^[0-9a-f]+ <.*>:$/ { body = 1; next }
    { m = $1 }
    m == "s_endpgm" { body = 0; next }
    body && m ~ /^s_(setkill|sethalt|sleep|setprio|trap|icache_inv|incperflevel|decperflevel|ttracedata|set_gpr_idx_off|set_gpr_idx_mode)$/ {
      n[m]++ }
    END { for (k in n) printf "  %s in a kernel body (%d): not implemented\n", k, n[k] }')"
  bad+="${internal:+$internal$'\n'}"

  priv="$("$READELF" --notes "$f" | grep -E 'PrivateSegmentFixedSize' |
    awk '$2 != 0' || true)"
  if [[ -n "$priv" ]]; then
    bad+="  private segment (scratch) in use: ${priv//$'\n'/; }"$'\n'
  fi

  if [[ -n "$bad" ]]; then
    echo "check_hsaco: $f uses instructions the simulator does not implement:" >&2
    printf '%s' "$bad" >&2
    status=1
  else
    echo "check_hsaco: $f OK"
  fi
done
exit "$status"
