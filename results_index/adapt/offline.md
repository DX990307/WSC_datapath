**C 的补充说明**：
- 规律大多是"线性切分但每设备页数不是整数"：KM 每设备 1.75 页（1 KB 块 7 块）、CFD 3.5 页（14 块）、MG ≈ 47 页、fft2d 56 页、MoE 704 / 1408 页（游程），且目标在 48 个设备上循环多圈（KM 32 圈）。所以"线性"必须允许实数 n 和 mod 48 循环；整数步长规律只在 atax（0.87）和 tc 上有用，owner 偏移只在 FW（目标 = owner 的下一个设备，1.00）和 sssp（0.64）上有用。
- PA（流式，被迁单元占远程读 0.97）全局规律命中 0.99（相邻相同），但在线覆盖只有 0.25（m = 2）–0.09（m = 8）：首访顺序和页号顺序不一致，相邻相同的段很短（16 页一段、交替两个设备），每次换段都回退。MT 没有份额 ≥ 0.6 的主读者（页内各 line 读者交错），不在 C 的范围内。
- 被迁字节很少的 workload（PR、tc、ivf、atax、sssp、embbag：被迁单元占远程读 ≤ 5%）全局拟合看起来"命中 1.00"是因为单元少（20–800 个），不说明有规律；所以另外报了"只看被迁单元占远程读 ≥ 10% 的 8 个 workload"：页、m = 2、回退：7 / 8 覆盖 ≥ 0.5，平均 0.77，精度 0.90。
- 通过条件按原文（≥ 1/3 的 workload 有 ≥ 50% 被迁字节被规律覆盖）：**带回退的在线学习通过（页 m = 2…4：9 / 8 / 7 个；1 KB m = 2…8：11 / 10 / 10 / 8 个）；不带回退的一次性预放置只有页 m = 8（6 个，精度 0.52）、1 KB m = 4 / 8（6 / 8 个，精度 0.23 / 0.33）勉强过线且精度不可接受**。第 3 步的预放置应实现成"按首访逐步放置 + 错一次就回退"。

## 1. A：热点早识别

定义（`offline_hot.py`）：
- (i) owner 端：每页按时间前 N 次远程读（L1V line 读，req ≠ own）里不同读者数达到 K 时判热点（在达到的那次读判定）。
- (ii) 翻译端（按 prompt 定义）：页首次访问（任何 GPM、读或写）后 T 内首次访问该页的不同 GPM 数（含 owner）≥ K。
- (ii-s) 滑动窗口：各 GPM 首次访问时间里，任意 T 窗口内有 K 个就判（在第 K 个到达时）。(ii-sr) 同上但只计每个 GPM 的第一次**读**。
- 召回 / 判定后 / 判定前都按 trace 里的远程读加权；误判 = 被判热点的非热点页的远程读 / 全部远程读。

要点：
- **owner 端 (i) 不可用**：一个 GPM 会连续读一页里很多条 line，前 N 次远程读往往只来自 1–3 个读者；N = 64、K = 3 召回也只有 0.70（ivf 0.19、atax 0），而 MT（每条 line 只被一个 GPM 读、但一页有很多 GPM）的流式页**100% 被误判**，bh 69% 被误判。
- **(ii) 按 prompt 的定义（从页首次访问起算 T）在 PR 上召回 0、atax 在 T ≤ 5 µs 时为 0**：这些热点页在读者到来前几十 µs 就被 owner 初始化（写）过。改成滑动窗口 (ii-s) 后召回 ≥ 0.97，但 fft2d 的私有放错页被误判 72–74%（别的 GPM 在某个 kernel 里短暂写这些页）。**只计第一次读 (ii-sr) 消掉了这类误判**（fft2d 0）。
- (ii-sr) T = 2 µs、K = 4 与 T = 5 µs、K = 6 都可以；前者召回略高（0.967 对 0.955），后者有害误判严格为 0。T = 10 µs / K = 3 召回 1.0 但误判 0.165（MT 流式、bh），不推荐。
- 剩下的误判主要是 bh 的"随机共享"页（每页很多 GPM、每条 line < 8 个读者）。这些页拆到环 12 不一定有害（它们本来也没有主读者），但会多出拆页开销；要更干净可以加 K_hot = 6（bh 0.33 → 仍高，说明 bh 的这些页确实被很多 GPM 同时读）。

## 2. B：同 buffer 传播

定义（`offline_buffer.py`，判定用推荐的 (ii-sr) T = 2 µs、K = 4）：buffer = driver 的一次分配。在 buffer 里第一个页被判热点（不论真假）的时刻 t_d，看 buffer 里还有多少页没有被任何 GPM 访问过（trace），其中真热点的比例（传播精度），这些真热点页的远程读占全部热点读的比例（传播覆盖 = 可以零代价改映射的部分），以及其中"它们自己被判定之前就会发生的读"（传播带来的增量）。门控传播：只有当 buffer 里已访问的页（≥ 4 个）中 ≥ 50% 已被判热点时才传播。集中度：buffer 内热点页按 owner 设备计数，最多设备的份额 ≥ 0.3 视为集中，和 P20 的 workload 级规则（热点读最忙 owner 份额 ≥ 0.3）比。

要点：
- 热点页在小 buffer 里**成片**：PR（32 页 rank 向量全热）、MM（16 页）、sssp（256 页）、atax（8 页）、tc（95 页里 84 页，连续）；这些 buffer 都 ≤ 256 页（N < 48 时整片在设备 1，所以集中度 1.0）。大 buffer 里热点**稀疏或交错**：ivf 1024 页里 768 页热但最长连续段只占 15%；embbag 13312 页里只有 222 页热。
- 第一次判定时还没被访问的页：mm 0.94、ivf 0.93、embbag 0.99、sssp 0.62、tc 0.51、atax 0.50、PR 0（rank 向量在读者到来前已被 owner 写过）。整片传播的精度：mm / sssp / atax 1.00、tc 0.98、ivf 0.74（读加权 0.94）、embbag 0.01（读加权 0.20，会把 69% 的全部远程读误拆）。
- **传播几乎不让热点识别更早**：增量 ≤ 0.2% 的热点读（mm、sssp、tc、atax），因为这些页自己被访问后 ~1 µs 内也会被 (ii-sr) 判出；例外 ivf +21%、embbag +13%（后者代价是大量误拆）。**传播的价值在代价**：被覆盖的热点读（50–93%）落在"还没被访问的页"上，可以直接改映射拆页，不需要 TLB shootdown / 挂起 / 拷贝。
- 门控（≥ 50% 已访问页被判热点）去掉了 embbag 的误拆（0），保住 ivf（覆盖 0.85、增量 0.21、误拆 4.9%）和 mm（0.46），但 sssp / tc / atax 的覆盖掉到 0.10 / 0.01 / 0：判定太早时已访问页很少、门槛不满足。所以推荐"小 buffer（≤ 256 页）整片传播，大 buffer 用门控"。
- 集中判断：buffer 级和 P20 workload 级一致（按热点读加权 0.99–1.00）：PR / MM / atax / tc 集中（份额 0.63–1.0），sssp / ivf / embbag 分散（0.04–0.11）。tc 的 95 页 buffer 按页份额 0.57、按读 0.66，也判集中。FW 的热点 buffer 在 baseline 里集中（1.0），但 8 个热点页都不在 trace 样本里，没有判定数据。

## 3. C：规律学习 / 可预放置比例

定义见 `offline_pattern.py` 开头。数据是 baseline 精确聚合（全部页，不受 trace 采样影响）。目标 = 份额 ≥ 0.6 的主读者（含 owner 自己的本地读），否则无目标；"被迁单元" = 有目标且 ≠ owner。设备按 1..48 编号（tile 24 跳过）。
- 全局拟合：每个 buffer 用全部被迁单元拟合每种规律（线性：最小二乘斜率 + 有理数吸附 + 相位 / 偏移扫描），命中按远程读加权。

## 4. D：收益/代价阈值 α

定义见 `offline_cost.py` 开头：计数访问 = 远程访问（R 或 W）；每 8 次评估一次；c_g = 已看到的全部访问（含 owner 本地）；目标 = 份额 ≥ 0.6 的主读者；收益 = Σ c_g ×（lat(g, owner) − lat(g, 目标)）；代价 = 2000 ns + L 行 × lat(owner, 目标) × w（页 L = 64，1 KB 块 L = 16）；收益 > α × 代价才迁，只迁一次。固定 256：任一 GPM 的远程计数到 256 就迁到它。净收益 = 判定之后的访问省下的延迟 − 代价（w = 1），相对全部远程访问延迟；"负收益迁移" = 事后净收益 < 0 的迁移。

要点：
- **α ≤ 0.5 会迁流式页**：MoE / PA 的流式页（每条 line 读一次，过去 ≈ 未来的假设失效）被大量迁移，净收益 PA −0.30…−0.98、MoE −0.15…−0.61；bh / embbag 的随机共享页也被迁（−0.01…−0.39）。α = 1 仍有 PA −0.05、MoE −0.05（页）/ −0.15（1 KB）。**α = 2（w = 1）起没有任何 workload 净亏 > 1%，流式页被迁 ≈ 0**，负收益迁移占比从 0.67 降到 0.18。α = 4 更保守但更晚（判定前 0.36），平均净收益降到 0.153。

- **1 KB 块**：固定 256 在块上太晚（判定前 0.51，KM 0.94），α = 2 的块粒度净收益 0.185，和页粒度（0.193）相当；1 KB 的好处（同页各块主读者不同）主要体现在 MT 这类页，但 MT 的块也没有份额 ≥ 0.6 的主读者。
- w = 0.5（拷贝代价减半）时对应的推荐是 α = 4（和 w = 1、α = 2 的门槛相同）。

## 5. E：同一 kernel 的 buffer 是否共享"步长"；跨 kernel 是否保持（10-23 追加）

脚本 `offline_stride.py`。每个 buffer 用全程精确聚合的整张页目标图（份额 ≥ 0.6 的主读者，含"主读者就是 owner"的页，按页读数加权）拟合线性切分 d = (c + ⌊i·σ + φ⌋) mod 48，n = 1/σ = 每设备页数。driver 按 WG 号连续分块派发（`distributeWGToGPUs`：每个 GPM 连续 28 × wgPerCU 个 WG，wgPerCU 从 baseline stdout 的 "total WG" 行取），所以每 WG 步进字节 = n × 4096 / (28 × wgPerCU)。pgcls 精确聚合**没有按 kernel 的读者计数**（只有每读者的 first_k / last_k / n_k），跨 kernel 部分用 trace 的 gk 列（W=128 v4m3；非热点 workload 1/4 页采样）。

结论：
- **同一 kernel 的规整 buffer 大多共享同一个步长**：CFD 7 个 buffer 全是 n = 3.5 页 / 设备（= 每 WG 512 B），32 对全部相同，B 只用 A 的 σ、自己学偏移命中 1.00（直接用 A 的全部参数也有 0.97）；bh 6 个 84 页 buffer 都是 n = 1.75（每 WG 256 B），34 对里 30 对相同（第 7 个 652 页 buffer 是 12.1），转用命中 0.89；tc、ivf 的成对 buffer 相同（1.00）；fft2d 两个 buffer 都是 n = 56（但第二个 buffer 首个 kernel 的 wgPerCU 不同，每 WG 字节 4096 对 8192）。
- **不共享的**：MoE（n = 1795 / 1795 / 1232 / 15 / 7，转用 0.15，允许 ×2^k 也只有 0.21，对自身拟合 0.86）、sssp（5.4 对 41，0.04 / 0.49）、PR（32 页的 rank 向量 n = 0.66，CSR 两个 buffer n = 83，比例 ≈ 126 ≈ 2^7 但转用只有 0.37）、MG（49 对 47，用 A 的 σ 命中 0.75 ≈ 自身 0.76，即 σ 近似可转用但规律本身不干净）。
- 每 WG 字节多数是 2 的幂（KM / bh / FW 256 B、CFD 512 B、fft2d 4096 B、tc 16 B），说明"每个 WG 处理固定字节数"是规律的来源，**在 WG→GPM 已知时可以按 kernel 一次学到、直接用到同 kernel 里元素大小相同的 buffer**；元素大小不同（PR、MoE、sssp）时简单按 2 的幂换算不够。
- **跨 kernel**：KM、fft2d、FW、CFD、bh 的页目标在相邻 kernel 之间 100% 一致，第一个 kernel 学到的规则用到后面 kernel 命中 0.93–1.00（fft2d 第二个 buffer 0.66 是规则本身只有 0.67）。**MG 例外**：两个大 buffer 的页目标在相邻 kernel 之间只有 0.19 / 0.05 一致（98 个 kernel 里 V-cycle 不同层级），第一个 kernel 的规则用到后面只有 0.87 / 0.03；和 P20 的 place_stability 结果（MG 换位置 0.73）一致。atax、MoE、PA、PR、tc、sssp、ivf、embbag、MM、MT 没有被多个 kernel 读且有足够目标页的 buffer。

## 6. F：LADM 风格放置表（对照 baseline）与 first-touch 估计（10-23 追加）

脚本 `offline_ladm.py`。**LADM 近似**：每个 buffer 取 trace 里第一个读它的全局 kernel（1/4 采样的 workload 只用样本页拟合，规则对全部页生效），页目标 = 该 kernel 内份额 ≥ 0.6 的读者（含 owner）；在有目标的页上拟合 lin / 步长 / owner 偏移三种"生成式"规则（相邻相同需要每页的观察，不是静态可得，不用），取命中最高的；**只有命中（读加权）≥ 0.8 且被迁页 ≥ 8 个、占该 kernel 该 buffer 读 ≥ 10% 时才应用**，目标只来自规则（不用每页真实主读者）。表格式同 P20 `-place-table`：`<1 KB 块号 = 物理地址 >> 10> <tile>`，一个页 4 行，只列换 home 的块；文件 `~/akita-exp-test/adapt/lists/<w>_ladm.txt`（yss2、yss3 各一份，md5 一致；16 个文件共 632 144 行，tile 都不是 24）。MM、MT 的表为空（没有可应用的 buffer）。
**first-touch**：页放到第一个访问它的 GPM（baseline 精确聚合里每读者的 first_ns，读或写；host 拷贝不是 GPM 访问，不计）。
**读×跳**：bound.md 的模型（只算 L1V 读，全程精确聚合，页粒度），除以 baseline（不动）的读×跳；"+M3+" = 每个读者保留 (reads − rep_intra − rep_cross)/reads，仍除以不含保留的 baseline。pg = 每页给它的主读者（P20 的 pg oracle），作参照。

结论：
- **LADM 近似**：16 个 workload 平均剩余读×跳 0.72（几何 0.56），+M3+ 0.32（0.16）；first-touch 0.62（0.41），+M3+ 0.22（0.12）；pg oracle 0.56（0.31），+M3+ 0.21（0.08）。LADM 在规律从第一个 kernel 起就成立的 workload 上等于 oracle：KM 0.06（= pg）、CFD 0.11（= pg）、bh 0.75（pg 0.74，first-touch 1.15）、atax / MoE 接近。**LADM 输的地方**：PA（主要的两个 31712 页 buffer 规律命中只有 0.08，静态分析认不出 → 不动，0.95 对 FT 0.09）、MG（第一个 kernel 的模式不适用于后面的 kernel，0.64 对 FT 0.26）、fft2d（第二个 buffer 第一个 kernel 的命中 0.66 < 0.8 没应用，0.25 对 FT 0.05）、热点类（PR / tc / sssp / ivf / MM / embbag 几乎不动，≈ 1.0）。
- **first-touch 赢在**流式和"写者 = 读者"的页（PA 0.09、fft2d 0.05、MG 0.26、MT 0.68 ≈ pg 0.67），首访者 ≠ 主读者的页只占远程读 8–9%（PA、fft2d、CFD）。**输在**：(1) 随机共享（bh：首访者 ≠ 主读者占 90% 远程读，读×跳 1.15 > baseline，多出 0.38 全来自随机共享页）；(2) 私有放错里"别的 GPM 先写 / 初始化"的页（FW：首访者 ≠ 主读者 25%，多出 0.12；KM / fft2d / MoE +0.03–0.04）；(3) 热点页给了首访者（PR +0.07、tc +0.12；sssp / ivf 反而 −0.02 / −0.05，因为首访者更靠近其他读者）。
- 作为对照 baseline：LADM 表适合跑在 KM、CFD、bh、MoE、FW、fft2d（部分）、atax 上（应用的页占远程读 0.6–1.0）；PR、tc、MM、sssp、ivf、embbag、MT、PA 上 LADM ≈ 不动（应用的页 ≤ 5% 远程读）。
